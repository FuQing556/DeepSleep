## 1. 游戏流程状态机

流程分两级，禁止用一个枚举同时承担跨场景和章节内状态。

```text
AppFlow:
Boot → FrontEnd ↔ GameplayLoading → Gameplay → FrontEnd

FrontEndState:
MainMenu ↔ RouteSelect ↔ ChapterSelect ↔ DifficultySelect
MainMenu ↔ Gallery / Settings / Credits

GameplayState:
Briefing → Tutorial/Flight ↔ SignatureEvent → Flight → BossIntro → BossFight
BossFight → Victory/Defeat → Result
Result → RetryChapter / RetryBoss(Casual) / NextChapter / FrontEnd
```

`Paused` 与 `UpgradeChoice` 是 Gameplay 覆盖状态，不是跨场景状态。任意可游玩状态按 `Esc` 进入 `Paused`，解除后回到原状态；二者不能同时激活。死亡先进入 `Defeat` 播放 0.9 秒失速，再进入 `Result`；死亡同帧立即停止收集、路线技能、升级请求和伤害结算。

| 状态 | 世界时间 | 玩家输入 | 敌人/关卡 | UI |
|---|---:|---|---|---|
| Boot | 0 | 禁用 | 只加载常驻配置/存档/设置/本地化/音频服务 | 黑屏淡入 |
| FrontEnd 各状态 | 0 | UI 导航/确认/返回 | 不生成玩法对象 | 标题、路线、章节、难度、图鉴、设置、制作名单 |
| RouteSelect | 0 | 选择 DeepSeek/Harness | 不生成 | 双路线卡片与攻击说明 |
| ChapterSelect | 0 | 选择已解锁线性章节 | 不生成 | 章节节点；不允许跳过未解锁主章 |
| DifficultySelect | 0 | 选择休闲/标准/困难 | 不生成 | 玩家可读差异；不直接展示内部倍率表 |
| GameplayLoading | 0 | 禁用 | 加载本章路线定义和对象池 | Loading/Fade，失败时返回前端并报错 |
| Briefing | 0 | 跳过/继续 | 只实例化预览，不启用伤害 | 最多 4 个对话泡 |
| Tutorial | 1 | 扑翼；路线技能按脚本解锁 | 教学对象 | 教学提示 |
| Flight | 1 | 扑翼、路线技能、暂停 | 时间轴运行 | HUD、升级三选一 |
| SignatureEvent | 1 | 扑翼及该事件允许的路线技能 | 独占标签按 Segment 执行 | 机制预警和角色表现 |
| BossIntro | 0 | 禁用 | 清场、Boss 入场 | Boss 名牌 |
| BossFight | 1 | 扑翼、路线技能、暂停 | Boss 状态机 | HUD、Boss 血条 |
| Paused | 0 | 继续/重开/退出 | 全部冻结 | 暂停菜单 |
| UpgradeChoice | 0 | UI 选择 | 全部冻结 | 当前路线卡池 |
| Victory/Defeat | 0 | 禁用 | 清弹并停止伤害 | 1.8s 胜利或 0.9s 失速演出 |
| Result | 0 | 重开/下一章/章节选择/主菜单 | 全部停止 | 成败与统计 |

规则：升级三选一弹出时 `Time.timeScale = 0`；只冻结玩法，不冻结 UI 动画。选择后恢复此前 timeScale，不得硬设为 1 破坏暂停状态。FrontEnd 与 Gameplay 场景职责见 `04_TechnicalArchitecture.md`，UI 细节见 `12_SystemsAndUXSpec.md`。

## 2. 输入

### 2.1 Windows 默认键位

| 动作 | 键鼠 | 触发条件 | 行为 |
|---|---|---|---|
| Fly | `Space` 或鼠标左键 | Press/Hold/Release | 点按冲量；按住持续升力；松开自然下落 |
| DeepSeek Shield | `Left Shift` | Press | 仅蓝线；能量满时启动 3 秒护盾 |
| Harness Aim | 鼠标右键 | Press/Hold/Release | 仅黑线；进入选区、拖动目标、松开确认范围攻击 |
| Pause | `Esc` | Press | 暂停/继续 |
| UI Navigate | 方向键/WASD/鼠标 | UI | 选择菜单 |
| UI Submit | `Enter`/`Space`/左键 | UI | 确认 |

禁止“双击空格开盾”。原因不是偏好，而是它会迫使程序延迟单击判定或误把快速扑翼当技能，导致操作不可预测。

### 2.2 Android 横屏触控

| 区域/控件 | DeepSeek | Harness |
|---|---|---|
| 左侧飞行区 | 点按、按住、松开分别映射 Fly Press/Hold/Release | 同左；瞄准时仍可由另一根手指飞行 |
| 右侧技能区 | 独立护盾按钮，只有可释放时高亮 | 空白处按住进入选区，拖动圆心，松开确认范围攻击 |
| 右上安全区 | 暂停按钮 | 暂停按钮 |

- UI 位置、按钮半径、飞行区和瞄准区边界来自输入/UI 配置，不写死在 PlayerMotor 或攻击控制器中。
- 使用触点 ID 分别追踪“飞行”和“技能/瞄准”手指，必须允许两者同时存在；任一手指离开只结束自己拥有的动作。
- 触摸输入与键鼠输入都输出同一个 `IPlayerInput` 快照，玩法层不得判断当前平台。
- 所有交互控件必须放在 Android Safe Area 内；系统手势边缘保留区不得作为唯一可点击区域。

### 2.3 输入缓冲

- Fly Press 缓冲：`0.10s`。按键发生在暂停/升级弹窗时不缓存。
- Fly Hold 在按下 `0.12s` 后生效；Release 当帧清除持续升力，不清除已有向上速度。
- DeepSeek Shield 缓冲：无。能量不足时只播放一次 `0.15s` 的能量条抖动，冷却 `0.4s`，不反复播音。
- 同一物理步多次 Fly Press 只消费一次。
- UI 获得焦点时，玩法 Action Map 必须禁用。

## 3. 相机与坐标

- 逻辑目标画面：1920×1080、16:9；Windows 和 Android 共用同一玩法坐标。
- Camera Projection：Orthographic。
- Orthographic Size：`5.4`。
- 可视世界范围：宽 `19.2`，高 `10.8`。
- 玩家固定目标 X：`-5.2`；仅 Y 方向受物理控制。
- 可游玩 Y 中心范围：`-4.35` 到 `4.35`；超出后按重碰撞处理并推回。
- 世界向左移动；玩家不沿 X 持续前进，避免大坐标漂移。
- 20:9 等宽屏不扩大生成/碰撞/瞄准范围，只在左右露出额外无碰撞背景；窄于 16:9 时完整显示 16:9 玩法区并使用装饰性留边，禁止裁掉危险物或 UI。

## 4. 玩家飞行

### 4.1 物理数值

| 字段 | 值 | 说明 |
|---|---:|---|
| GravityScale | 2.35 | 使用 Physics2D 全局重力 Y=-9.81 |
| TapRiseVelocity | 6.8 u/s | 按下时把 Y 速度至少抬到该值 |
| HoldThreshold | 0.12s | 超过后视为按住 |
| HoldLift | 24 u/s² | 按住期间持续向上加速度 |
| MaxRiseSpeed | 7.6 u/s | 上升限速 |
| MaxFallSpeed | -8.5 u/s | 下落限速 |
| RotationUp | +18° | 上升视觉角度 |
| RotationDown | -32° | 下落视觉角度 |
| RotationSmooth | 10 | `1-exp(-k*dt)` 平滑，不影响碰撞体 |
| HurtKnockbackY | 2.2 u/s | 受伤时最低向上反弹速度 |

`Rigidbody2D` 为 Dynamic，Continuous Collision Detection，Interpolate。角色碰撞体不随 Sprite 翻转或旋转；旋转只作用于 `VisualRoot` 子物体。

### 4.2 玩家碰撞体

- `CapsuleCollider2D`，尺寸 `0.90×0.72u`，Direction=Horizontal。
- Offset `(0,-0.08)`。
- 角色图片可以大于碰撞体，鲸尾、头发、鳍耳不得计算伤害。
- 伤害判定以碰撞体接触为准，不能用屏幕像素或 Sprite bounds 代替。

## 5. 生命、伤害与护盾

### 5.1 生命

- 最大生命：3 心。
- 初始生命：3 心。
- 普通敌弹、敌人身体：1 心。
- 障碍、上下边界、Boss 身体：标准/困难为 2 心，休闲为 1 心；难度表见第 12 节。
- 受伤无敌：`0.80s`，从扣血同一物理步开始。
- 无敌闪烁：每 `0.08s` 切换透明度 1/0.35，结束强制恢复 1。

伤害处理顺序必须固定：

1. 已死亡：拒绝。
2. 护盾生效：消费该碰撞，不扣血。
3. 无敌帧：拒绝。
4. 同步设置无敌标记。
5. 扣血并广播结果。
6. 生命 ≤0：进入死亡，禁用输入与攻击。

同一物理步被多个 Collider 命中只能扣一次血。

### 5.2 DeepSeek 白米饭能量与护盾

| 字段 | 值 |
|---|---:|
| MaxEnergy | 100 |
| StartEnergy | 0 |
| RiceEnergy | 20 |
| ShieldCost | 100 |
| ShieldDuration | 3.0s |
| ShieldHitRule | 持续时间内无限挡伤，不缩短时长 |

本节仅适用于蓝色 DeepSeek 路线。护盾启动时能量立即归零；不能提前取消；护盾期间仍可拾取白米饭并为下一次充能。护盾只防伤害，不允许穿过实体障碍；与管道接触时仍执行位置分离，防止结束瞬间卡死。Harness 不使用这套白米饭护盾资源，其能源与攻击共用，见 6.2。

## 6. 路线专属攻击

### 6.1 DeepSeek 自动索敌饭团

| 字段 | 值 |
|---|---:|
| FireRate | 3.2 发/秒 |
| Damage | 10/发 |
| ProjectileSpeed | 13 u/s |
| Lifetime | 2.2s |
| MuzzleOffset | `(0.85, 0.05)` |
| Targeting | 前方范围内自动选择有视线目标 |
| TurnRate | 240°/s |
| RetargetInterval | 0.12s |

进入 Tutorial 后启用自动攻击；没有合法目标时不发射。目标与玩家之间被 Obstacle 层挡住时不能锁定；已发射饭团命中障碍立即销毁。BossIntro 暂停射击，BossFight 恢复。子弹出屏、命中或寿命结束必须回对象池。

### 6.2 Harness 手动范围攻击

| 字段 | 值 |
|---|---:|
| MaxEnergy | 180 |
| StartEnergy | 90 |
| AttackCost | 60 |
| PassiveRegen | 4/秒 |
| Cooldown | 2.4s |
| Radius | 2.15u |
| DamageNormal | 120 |
| DamageBoss | 45 |
| ExecuteDelay | 0.28s |

Harness 选区使用独立输入；选区查询和伤害结算忽略 Obstacle 层，但不会摧毁障碍。能量不足或冷却未结束时禁止确认并显示灰色选区。一次释放只结算一次伤害，禁止用多段碰撞偷偷翻倍。

Windows 绑定为右键按下进入选区、拖动光标移动圆心、松开释放；Android 由右侧瞄准区同构完成，并允许左侧飞行手指并行。选区圆心限制在 16:9 逻辑玩法区内且与玩家距离≤`12u`；超出时投影到边界，不允许利用宽屏装饰区点到玩法区外。瞄准期间世界不减速，角色飞行继续响应。

### 6.3 共用命中规则

- 一发只命中一个可受伤目标。
- 障碍吸收玩家弹，但不受伤。
- 普通怪死亡前的同帧重复命中只结算一次经验。
- Boss 无受击无敌；单发子弹不能因多个 Collider 对 Boss 重复伤害。

## 7. 收集、经验与升级

### 7.1 拾取物

| 类型 | 效果 | 磁吸 | 消失 |
|---|---|---:|---:|
| 白米饭 | 标准难度 DeepSeek +20 护盾能量；Harness 不生成 | 1.2u | 12s 或出屏 |
| 算力凭证 | 标准难度 Harness +30 攻击能量；DeepSeek 不生成 | 1.2u | 12s 或出屏 |
| Token 碎片 | +1 XP | 1.5u | 12s 或出屏 |

普通怪固定掉 1 Token；精英怪掉 2。白米饭只由关卡时间轴和 Boss 阶段转换生成，不由每次命中 Boss 掉落。

### 7.2 升级阈值

- 等级 1 初始 XP 0。
- 达到累计 XP `5`：第一次三选一。
- 达到累计 XP `12`：第二次三选一。
- 达到累计 XP `21`：第三次三选一。
- 第一关最多升级 3 次；多余 XP 只计入结算。

每次弹出 3 张不同卡。若候选池不足，宁可少显示一张也不能重复同一 Buff。

### 7.3 DeepSeek 首关 Buff 池

| ID | 显示名 | 精确效果 | 上限 | 视觉反馈 |
|---|---|---|---:|---|
| BUF_PARALLEL | 并行采样 | 同时发射 2 发，角度 ±4°；每发 70% 当前伤害 | 1 | 两个枪口光点 |
| BUF_PARAM | 参数扩容 | 玩家弹伤害 ×1.25 | 3 | 子弹体积 +8%/层 |
| BUF_QUANT | 轻量量化 | 射速 ×1.20，单发伤害 ×0.92 | 2 | 发射残影 |
| BUF_CACHE | KV 缓存命中 | 白米饭能量 +10；磁吸半径 +0.35u | 2 | 蓝色缓存环 |
| BUF_CONTEXT | 上下文扩展 | 最大生命 +1，并立刻回复 1 心 | 1 | HUD 新增心槽 |
| BUF_SEARCH | 联网搜索 | 每第 6 发变成穿透弹，可穿 2 个普通怪 | 1 | 放大镜弹头 |

倍率统一按如下顺序计算：`基础值 × 所有加法层结果 × 所有乘法 Buff`，最终伤害四舍五入到整数，射击间隔下限 `0.16s`。

### 7.4 Harness 首关 Buff 池

| ID | 显示名 | 精确效果 | 上限 | 视觉反馈 |
|---|---|---|---:|---|
| HA_PARALLEL | 并行代理 | 主攻击命中普通目标后，`0.18s` 后打击最近的未命中目标，造成当前普通伤害的 `45%`；对 Boss 只播第二执行环，不追加伤害 | 1 | 第二个红黑执行环 |
| HA_PARAM | 参数预算 | 选区半径 `×1.12` | 2 | 圆环外沿增加刻度 |
| HA_QUANT | 量化账单 | 攻击成本 `-8`，普通/Boss 伤害 `×0.95` | 2 | 账单数字压缩动画 |
| HA_CACHE | 热缓存 | 被动恢复 `+1.5/s`，每张算力凭证额外 `+5` 能量 | 2 | 能量条缓存脉冲 |
| HA_CONTEXT | 上下文池 | 最大能量 `+30`，并立刻恢复 `30` | 2 | 能量条新增分段 |
| HA_SEARCH | 精确检索 | 对 Boss 明确标出的真弱点伤害 `×1.25`；ExecuteDelay `-0.08s` | 1 | 真弱点方括号变白 |

Harness 计算顺序固定为：基础数值 → 加减值 → 乘法 → 钳制。最终攻击成本不得低于 `40`，ExecuteDelay 不得低于 `0.12s`，选区半径不得高于 `2.70u`。三选一只能从当前路线卡池取卡；UI 不得给 Harness 显示“白米饭”类说明。

### 9.3 Boss 超时

BossFight 进入 70 秒仍未结束时触发温和狂暴：所有弹速 ×1.15，不增加子弹数量。没有突然秒杀或隐藏倒计时。

## 10. 清场与转场

Flight 时间轴结束时：

1. 停止新生成。
2. 所有普通敌人停止发弹。
3. 现存敌弹在 0.6 秒内淡出并回池。
4. 普通敌人向左加速离场；1.5 秒后仍存在则回池。
5. 保留当前路线资源（白米饭或算力凭证）和 Token 1 秒供玩家拾取，之后回池。

7. 进入 BossIntro，5 秒后 BossFight。

## 12. 三档难度（已确认）

标准难度是所有基础数值和 QA 的权威基线。`DifficultyProfile` 只能修改下表白名单字段：

| 项目 | 休闲 | 标准 | 困难 |
|---|---:|---:|---:|
| 玩家普通受伤 | 1 | 1 | 1 |
| 玩家重碰撞 | 1 | 2 | 2 |
| 敌弹速度 | ×0.82 | ×1.00 | ×1.12 |
| Boss HP | ×0.85 | ×1.00 | ×1.08 |
| 普通通道净高 | +0.40u | 原值 | -0.22u |
| 事件预警 | ×1.25 | ×1.00 | ×0.90 |
| 路线资源 | ×1.20 | ×1.00 | ×0.90 |
| Boss 重试 | BossIntro 内存快照；最高 A | 重开整章 | 重开整章 |

休闲、标准初始开放；任一路线标准难度通关 C1 后解锁困难。豆包气泡段在任何难度都禁止生成敌人、敌弹或额外障碍，只可调整曲线振幅、相位、净高和预览时间。难度不得修改玩家碰撞体、基础重力、输入延迟、伤害预警颜色或 Boss 必需机制。

倍率计算规则必须确定：

- Boss `scaledMaxHP = CeilToInt(baseMaxHP × hpMultiplier)`；三阶段阈值按当前最大 HP 的 `2/3`、`1/3`，四阶段按 `3/4`、`1/2`、`1/4`，均在 `currentHP ≤ CeilToInt(scaledMaxHP × ratio)` 后、当前最短 Pattern 循环结束时转换。
- 敌弹速度与预警时长保留到 `float`，不提前舍入；伤害值不乘难度倍率。
- 路线资源倍率改变每个拾取物恢复值，不改变图片数量：白米饭 `RoundToInt(20 × resourceMultiplier)`，算力凭证 `RoundToInt(30 × resourceMultiplier)`；BUFF 增量在难度倍率之后相加。
- 普通通道净高只作用于允许缩放的管道/走廊配置；Boss 明写的最小安全口是硬下限，困难也不得突破。
