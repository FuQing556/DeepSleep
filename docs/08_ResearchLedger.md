# 08｜AI 梗与角色考据记录

> 首次检索：2026-08-31；术语补充检索：2026-09-04。互联网内容会变化；产品能力在正式制作对应关卡前需复核。本文只记录证据与判断，不拥有玩法数值。

## 1. 判断方法

1. 产品能力优先官方产品页、官方博客、论文、品牌规范。
2. 中文互联网梗需要多处重复或可追溯创作者，不用一个营销号标题定性。
3. GitHub 仓库先看作者自述、star/社区体量、许可证和素材来源，不能因为“开源”就当公认设定。
4. 用户提供的图可锁定本项目美术方向，但在找到作者/许可证前不等于可把原图收入开源仓库。
5. 查不到就是“未证实”，不拿搜索结果缺失反向证明不存在。
