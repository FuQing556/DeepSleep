# 09｜双主角路线与 AI 遭遇设计 v1.0（内容参考，路线失效）

> 2026-09-04：双独立路线和扑翼飞行已失效。豆包、Opus、Grok等AI事件概念继续保留，并按 `18_CoopShooterGameplaySpec.md` 改造成双鲸合作遭遇。

> 状态：核心方向、Kimi 身份、三档难度和无永久数值成长均由用户锁定；决策见 `14_DecisionRegister.md`。  
> 目标：把 AI 梗变成玩家能看见、能预判、能操作的机制，而不是 Logo 换皮或说明书笑话。

## 1. 不得改动的产品规则

1. 这是 2D 横版扑翼飞行游戏。按下一次产生一次向上冲量；按住时持续提供升力；松开后自然下落。
2. 剧情按线性章节推进，不做随机无尽主流程。
3. 蓝色 DeepSeek 鲸鱼娘与黑红 DeepSeek Harness 鲸鱼娘是两条独立路线的可玩主角。
4. 两条路线可以复用背景主题和 AI 角色，但不得复用同一份生成时间轴后只改数值。障碍布置、资源节奏、Boss 解法分别编排。
5. 其他 AI 主要作为 Boss、专属事件、辅助角色或道具。没有独特机制的角色不进入关卡。
6. 所有角色采用统一二次元 Q 版：普通角色 2.4–2.8 头身；巨型 Boss 仍保持 Q 版头身，只放大画面占比。
7. Grok 的成人内容仅转译成圣光、迷雾和遮挡梗，不生成或展示色情内容。

## 2. 共用飞行输入

### 2.1 飞行手感

| 输入状态 | 运行时行为 | 目的 |
|---|---|---|
| Press | 当帧把垂直速度至少抬到 `TapRiseVelocity=6.8u/s` | 点一下明确飞一下 |
| Hold | Press 后超过 `0.12s`，持续施加 `HoldLift=24u/s²` | 允许按住稳定上升 |
| Release | 立即停止持续升力，重力恢复完整作用 | 松开自然下落 |
| Hold 上限 | 垂直速度限制为 `MaxRiseSpeed=7.6u/s` | 防止长按冲出镜头 |
| 下落上限 | `MaxFallSpeed=-8.5u/s` | 保持可控 |

实现要求：Press 冲量与 Hold 升力必须是两个明确步骤；不能每个 FixedUpdate 重复执行 Press，也不能用动画位移代替 Rigidbody2D 物理。

### 2.2 输入冲突红线

- 飞行输入不能同时承担 Harness 的选区蓄力，否则玩家为了上升会误放大招。
- Harness 的范围攻击必须暴露独立的 `AimAttack(screenPosition)` 和 `ConfirmAttack()` 动作。
- 最终绑定：Windows 左键/Space 飞行，右键按下进入选区、拖动目标、松开释放；Android 使用配置化左侧飞行区与右侧技能/瞄准区，并以不同 touchId 支持两指并发。蓝色 DeepSeek 路线在 Windows 用 `Left Shift`、Android 用独立护盾按钮，不占 Harness 瞄准输入。

## 3. 两条主角路线

### 3.1 蓝色 DeepSeek：自动索敌、饭团连射

| 字段 | 实现基线 |
|---|---|
| 角色定位 | 反应快、便宜、能持续输出，但会被信息墙和实体障碍挡住 |
| 攻击输入 | 无；进入战斗状态后自动攻击 |
| 索敌范围 | 角色前方 `10.5u × 7.2u` 矩形 |
| 目标优先级 | 可见 Boss > 距玩家最近且可见的主动攻击敌人 > 最近可见敌人 |
| 视线检测 | Player 到目标中心做 `Physics2D.Linecast`，Obstacle 层命中即不可锁定 |
| 射速 | `3.2 发/秒` |
| 单发伤害 | `10` |
| 弹速 | `13u/s` |
| 转向 | 每秒最大 `240°`；不是瞬间拐弯 |
| 障碍规则 | 饭团弹命中任何实体障碍立即销毁，不造成穿透伤害 |
| 无目标行为 | 不发射；每 `0.12s` 重选目标，避免持续扫 Linecast |
| 主要资源 | 白米饭：护盾与路线恢复；Token：升级 |

视觉：发射物必须看得出是小饭团/饭粒光团，不再使用抽象蓝色子弹冒充；自动索敌时目标脚下出现 0.18 秒蓝色小鲸标记。

### 3.2 黑红 Harness：手动选区、高耗能穿障范围攻击

| 字段 | 实现基线 |
|---|---|
| 角色定位 | 高效、精确、烧钱；少出手，但一次清理大片区域 |
| 攻击输入 | 独立指针选区；确认后释放 |
| 最大能量 | `180` |
| 初始能量 | `90` |
| 单次成本 | `60` |
| 被动恢复 | `4/秒`，Boss 演出和暂停期间停止 |
| 拾取恢复 | 终端账单/算力凭证 `+30`；不吃蓝线的白米饭能量 |
| 最短间隔 | `2.4s`；能量不足仍不能释放 |
| 选区半径 | `2.15u` |
| 基础伤害 | 普通敌人 `120`；Boss `45` |
| 预警/确认 | 选区出现红黑虚线圆；合法目标白边，能量不足时变灰并抖动 |
| 障碍规则 | 选区和伤害查询忽略 Obstacle 层；障碍不被摧毁，只是不会挡住攻击 |
| 伤害时点 | 确认后 `0.28s` 落下终端执行环，统一结算一次；不是持续多段伤害 |

“烧钱”用每次释放弹出的算力账单、能量骤降和低频重击体现；禁止用掉真钱、付费弹窗或诱导消费表达。

### 3.3 路线差异的最低验收

同一 AI 主题在两条路线中至少有一项不同：空间路线、攻击目标、资源奖励、Boss 破招窗口。以下例子为强制基线：

- DeepSeek 路线遇到掩体后必须调整飞行高度寻找射线；Harness 可以隔墙点杀，但需要为下一次攻击保留能量。
- DeepSeek 路线奖励连续锁敌和饭团射速；Harness 路线奖励一次覆盖多个目标和不空放。
- 专属教程、时间轴资产和结算统计分开：`Lxx_DS_*` 与 `Lxx_HA_*`。

## 4. 已锁定的专属事件

### 4.1 豆包：曲折话术气泡通道

豆包段是 12–18 秒的独立稳定飞行考试。期间停止生成其他障碍、小怪和敌弹；攻击系统可继续播放待机，但没有可攻击目标。

屏幕上、下各由连续气泡链构成实体边界，中间留下唯一可通行走廊。气泡内短句由 TMP 动态渲染，不烘焙进图片：

- “我直接给你最一针见血的……”
- “最客观、最直接、最清晰地说……”
- “先说结论——”
- “你这个问题非常关键。”

正常难度走廊函数（以进入事件后的秒数 `t` 计算）：

```text
CenterY(t) = 0.70*sin(2πt/7.5) + 0.24*sin(2πt/3.8 + 0.8)
GapHeight   = 2.35u
ScrollSpeed = 4.0u/s
```

生成器每 `0.72u` 沿 X 放一个气泡锚点，上链位置为 `CenterY + GapHeight/2 + bubbleHalfHeight`，下链为 `CenterY - GapHeight/2 - bubbleHalfHeight`。相邻锚点 Y 差限制在 `0.34u`，超出时钳制，避免曲线突然折断。气泡 Collider 使用简化 Capsule/Box，不从透明轮廓自动生成。

可读性规则：

1. 玩家进入前 1.2 秒先展示三枚无伤预览泡，明确“上下都会封”。
2. 走廊中线变化速度绝不超过玩家一次短按可修正的幅度。
3. 气泡边框为粉蓝实线，触碰伤害 `1`；不能与无伤台词泡共用白色虚线。
4. 事件最后 2 秒曲线逐渐回到 `Y=0`，给后续场景复位。
5. 后续若增加难度，只改 `GapHeight`、振幅和相位；不得偷偷叠加小怪。

### 4.2 Claude Opus：最高的山突然站起来

旧“参数纸堆成静态山”方案作废。Opus 是巨大 Q 版半身角色，从屏幕下方突然跃起，利用“最高的山”制造体量冲击。

一次标准事件总长 `4.6s`：

| 时间 | 画面与判定 |
|---:|---|
| 0.00–0.65 | 地面出现宽 `5.6u` 的橙金半透明影子；屏幕边缘显示向上箭头；无伤 |
| 0.65–1.05 | Opus 半身快速上跳，EaseOutBack；仍无伤，轮廓由黄转红 |
| 1.05–2.55 | 身体碰撞生效；巨大半身占屏幕下方约 68%，头顶和发饰形成“山峰”；上方至少保留 `2.05u` 净通道 |
| 2.55–3.05 | Opus 做一次短促审稿/盖章动作，产生横向风压，只推 Y 速度、不扣血 |
| 3.05–3.55 | 下落离场；碰撞在下落开始 `0.18s` 后关闭，避免尾部拖判定 |
| 3.55–4.60 | 镜头轻震衰减、恢复滚动 |

首遇只从下方出现，不加入倒悬版本。角色 Sprite 与伤害 Collider 分离：头发、袖摆、光环不伤人；半身主体用不超过 3 个 Collider。镜头震动位置幅度≤`0.10u`、时长≤`0.28s`，不得破坏扑翼判断。

Opus 采用用户参考中的橙发 Claude 系宽松锚点：橙色长发、黑/象牙白学者裙装、温和但有压迫感的审稿姿态。重点是巨大 Q 版半身跃起的体量和动作，不像素级照抄来源图片，也不把参考图中的对白烘焙进素材。

### 4.3 Grok：圣光与迷雾遮挡

Grok 本体在右侧探头或掀开“限制帘”，随后一块被圣光/迷雾处理的区域覆盖前景。没有裸露人物或色情素材。

推荐机制 `GR_VISIBILITY_PATCH`：

- 0.8 秒前用洋红边框标出即将被遮挡的矩形。
- 遮挡持续 3.2 秒，Alpha 从 0→0.88；最高难度才允许完全不透明 0.7 秒。
- 遮挡出现前，所有真实障碍轮廓在 HUD 层保留 0.35 Alpha 的安全描边；玩家能靠记忆和边缘提示通过。
- 首次事件只遮屏幕中部 35% 面积，不遮玩家和全部安全通道。
- 该段不生成不可预见的高速弹。

## 7. 程序必须采用的数据边界

```text
ChapterDefinition
  ├─ route: DeepSeek | Harness
  ├─ orderedSegments[]
  ├─ bossDefinition
  └─ rewardTable

SegmentDefinition
  ├─ type: Combat | BubbleCorridor | GiantJump | VisibilityPatch | Boss
  ├─ duration
  ├─ routeSpecificPayload
  └─ forbiddenConcurrentTags[]
```

- `BubbleCorridor` 强制带 `forbiddenConcurrentTags=[Enemy,Obstacle,EnemyProjectile]`。
- `GiantJump` 自己管理预警、碰撞开启/关闭和镜头震动，不伪装成普通 `ObstacleSpawner`。
- `VisibilityPatch` 只改变渲染和提示，不得直接关掉碰撞或修改真实物体位置。
- 两条路线的角色攻击实现不同策略接口，但飞行控制器共用，禁止复制两套物理代码。

## 8. 已确认决策

1. Kimi K3：先辅助、后因上下文过载成为 Boss、战后恢复友军。
2. 难度：休闲/标准/困难；豆包段永不叠怪。
3. 永久成长：不加永久数值，只解锁内容与外观。
4. Neuro/Evil Neuro：独立隐藏 Boss 关，不遗漏。
