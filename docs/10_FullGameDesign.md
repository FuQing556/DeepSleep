## 1. 完整产品目标

### 1.1 一句话

玩家选择蓝色 DeepSeek 鲸鱼娘或黑红 Harness 鲸鱼娘，在 AI 网络梦境中以扑翼飞行穿越线性章节；两条路线共用飞行手感，却分别用“自动索敌但会被挡住的饭团”和“手动选区、高耗能、穿障范围执行”解决同一批 AI 梗事件和 Boss。

### 1.2 完整版范围

- 主线：序章 + 6 章。
- 每章两份独立路线脚本：`DS` 与 `HA`。
- 主线 Boss：Gemini、Claude、Kimi K3（先友军→上下文过载 Boss→恢复友军）、Grok、GLM、ChatGPT。
- 主要事件/辅助：豆包、Opus、Codex、Claude Code、OpenCode、Zcode、即梦、MiniMax、Qwen、Perplexity。
- 隐藏内容：Neuro/Evil 双人关、Siri/小爱语音助手博物馆；不阻塞主线发布。
- 首轮单路线目标时长：35–50 分钟；双路线和隐藏内容合计约 80–120 分钟。
- 不接真实模型 API，不联网，不收集用户输入，不做账号和排行榜。

### 1.3 玩家体验支柱

1. **飞得顺**：点按立刻上升，长按持续升力，松开可预期地下落。
2. **看得懂**：黄色预警、红色伤害、白虚线无伤、蓝色安全/辅助；笑话不能破坏判定可读性。
3. **两条路线真不同**：不是换颜色；同一事件拥有不同目标、资源、破招窗口和统计。
4. **梗能操作**：AI 梗必须变成走廊、遮挡、回滚、复制、引用、规则墙或资源决策。
5. **失败可解释**：结果页能指出玩家死于哪一类伤害、在哪个机制、如何改进。
6. **制作可控制**：先定机制和资产表，再生图；候选图不能直接冒充可用 Sprite。

## 2. 完整游戏流程

```text
Boot
  → FrontEnd
      → MainMenu
      → RouteSelect
      → ChapterSelect
      → DifficultySelect
      → Briefing
  → Loading
  → Tutorial/Flight
      ↔ Pause
      → MidEvent
      → Flight
      → BossIntro
      → BossFight
  → Result
      → RetryChapter / RetryBoss（按难度规则） / ChapterSelect / NextChapter
  → Gallery / Settings / Credits
```

### 2.1 首次启动

1. 显示光敏/闪烁提示与“本作是同人梗游戏，非各公司官方角色”短声明。
2. 默认语言简体中文；若系统语言非中文则先显示语言选择。
3. 进入标题页；第一次点击开始后直接进入路线选择。
4. 选择路线后播放不超过 12 秒的操作演示，再进入序章。

### 2.2 回流启动

主菜单默认选中“继续”，继续到上次已解锁但未通关的最早章节。玩家仍可返回章节选择重玩、换路线或换难度。

## 3. 单章循环

| 阶段 | 目标时长 | 玩家做什么 | 系统责任 |
|---|---:|---|---|
| Briefing | 8–15s | 看本章 AI、机制图标、路线目标 | 不写长剧情；可立即跳过 |
| Warm-up | 20–35s | 用安全组合复习飞行与攻击 | 不造成突发重伤 |
| Combat A | 45–70s | 敌人、门、路线资源 | 交付第一次升级 |
| Signature Event | 12–25s | 体验本章独占机制 | 事件之间互斥，保证可读 |
| Combat B | 45–80s | 把事件机制与路线能力组合 | 交付第二/第三次升级 |
| Clear | 4–7s | 拾取、复位 | 清除伤害体，不偷袭 |
| Boss Intro | 4–7s | 看巨大 Q 版入场 | 输入禁用，UI 可跳过已看演出 |
| Boss | 45–90s | 学习 3–4 阶段并击破 | 每阶段只引入一个新规则 |
| Result | 不限 | 看原因、评级、解锁 | 一键重试和下一章 |

每章标准总时长 4–7 分钟。章节变长时增加不同段落，不能单纯延长相同刷怪循环。

## 4. 双路线完整定位

### 4.1 共用内容

- 完全共用 `PlayerMotor`、重力、边界、生命、无敌帧和基础碰撞体。
- 共用章节主题、背景、Boss 身份、叙事节点和大部分环境素材。
- 共用 Token 升级触发规则，但 Buff 池、能量条、攻击统计分别实现。

### 4.2 DeepSeek 蓝线

- 认知负担主要来自飞行和寻找可见射线；攻击自动进行。
- 路线喜欢连续小目标、可绕开的实体掩体、长输出窗口。
- 白饭只用于护盾；护盾不穿实体。
- 结算关注：锁定有效时间、饭团被墙吸收数量、护盾时机、连续击破。

### 4.3 Harness 黑线

- 认知负担来自飞行与右键选区同时进行；攻击不自动。
- 路线喜欢成组目标、墙后弱点、真假目标、能量节拍和低频大窗口。
- 算力能量同时决定攻击次数；没有蓝线护盾。
- 结算关注：有效选区率、平均覆盖数、空放次数、每 60 能量伤害、穿障击破。

### 4.4 禁止的伪差异

- 同一时间轴只乘 HP/速度。
- 蓝线和黑线生成相同敌人位置，只把拾取物换图。
- Harness 通过无限能量连续轰炸，或 DeepSeek 自动攻击无视掩体。
- Boss 只因路线不同而增加无敌时间；路线差异必须来自可操作机制。

## 5. 局内成长

### 5.1 共同规则

- Buff 只在当前章节有效，离开章节全部清空。
- 每次升级展示 3 张互不重复卡；选择时世界冻结、UI 使用未缩放时间。
- 一个 Buff 最多改变一项主要行为和一项视觉反馈，禁止一张卡同时改五个系统。
- 章节脚本以“无 Buff 可通关”为硬门槛；Buff 只改变打法和容错，不修复必死设计。

### 5.2 DeepSeek Buff

沿用 `01_GameplaySpec.md` 的并行采样、参数扩容、轻量量化、KV 缓存、上下文扩展、联网搜索六项。

### 5.3 Harness Buff 设计

正式数值在写入 `01_GameplaySpec.md` 后才拥有运行时权威；当前机制已锁定：

| ID | 显示名 | 行为 | 视觉 |
|---|---|---|---|
| HA_PARALLEL | 并行代理 | 主选区结算后，对最近的未命中普通目标追加一次较弱执行；Boss 不吃第二次伤害 | 第二个小执行环 |
| HA_PARAM | 参数预算 | 扩大选区半径；层数越高越容易覆盖成组目标 | 圆环外沿增加刻度 |
| HA_QUANT | 量化账单 | 降低攻击成本但轻微降低伤害；用于提高出手频率 | 账单数字压缩动画 |
| HA_CACHE | 热缓存 | 提高被动恢复与算力凭证收益 | 能量条出现缓存脉冲 |
| HA_CONTEXT | 上下文池 | 增加最大能量并立即补充同量能量 | 能量条新增分段 |
| HA_SEARCH | 精确检索 | 对被 Boss 明确标出的真弱点提高伤害并缩短执行延迟 | 方括号锁定变白 |

六张卡可以复用现有六枚 Buff 图标，但标题、说明和数值必须按路线加载，不能在 UI 上把“白饭+10”显示给 Harness。

## 6. 难度方案（已确认）

推荐提供三个难度。标准难度拥有权威数值；其他难度只通过 `DifficultyProfile` 修饰允许的字段。

| 项目 | 休闲 | 标准 | 困难 |
|---|---:|---:|---:|
| 玩家普通受伤 | 1 | 1 | 1 |
| 玩家重碰撞 | 1 | 2 | 2 |
| 敌弹速度 | ×0.82 | ×1.00 | ×1.12 |
| Boss HP | ×0.85 | ×1.00 | ×1.08 |
| 普通通道净高 | +0.40u | 原值 | -0.22u |
| 事件预警 | ×1.25 | ×1.00 | ×0.90 |
| 路线资源 | ×1.20 | ×1.00 | ×0.90 |
| Boss 重试 | 保存入场快照 | 重新开始本章 | 重新开始本章 |

硬规则：

- 豆包段任何难度都不生成敌人或敌弹；只调整走廊振幅、相位、净高和预览时间。
- 困难不通过成倍增加弹量制造遮屏；优先改变安全口位置、真假窗口和节奏。
- 休闲不是无敌模式；额外提供独立“辅助设置”，例如受伤后自动护盾、瞄准减速等。

## 7. 章节外成长（已确认）

推荐不做攻击、血量、能量的永久加点。永久内容只有：

- 章节和两路线进度。
- 休闲/标准默认可选，困难在任一路线通关第一章后解锁。
- 图鉴：AI 角色、梗来源、Boss 攻击演示、我方原创转译说明。
- 挑战章和隐藏关。
- 不改变碰撞体和数值的外观、头像框、菜单桌宠。
- 每章 DS/HA 独立评级与最佳统计。

这样重玩依靠技术、路线理解和 Buff 组合，而不是刷数值压过关卡。

## 8. 评级与统计

### 8.1 评级

通关评级使用三个徽记，不用一个难以解释的总分：

| 徽记 | DeepSeek 条件 | Harness 条件 |
|---|---|---|
| 生存 | 剩余生命达到章节标准 | 相同 |
| 执行 | 自动锁定有效率、Boss 输出窗口利用率 | 空放≤章节标准、平均覆盖数达标 |
| 收集 | Token 与白饭收集率达标 | Token 与算力凭证收集率达标 |

三徽记全得为 S；两枚 A；一枚 B；仅通关 C。困难难度只增加徽记边框，不改变解锁主线所需条件。

### 8.2 结果页

- 通关/失败、路线、章节、难度。
- 存活时间、剩余生命、Boss 用时。
- 本局 Buff。
- 路线专属攻击效率。
- 收集率和错过数量。
- 主要失败来源和最后一次受伤的机制名。
- 新纪录、解锁物和下一章按钮。

## 9. 失败、重试与检查点

- 标准/困难死亡后默认重开整章；章节目标 4–7 分钟，不设置隐形续命。
- 休闲难度到达 BossIntro 时保存内存快照：HP、能量、Buff、统计和 authored seed。Boss 死亡可从该快照重试，退出章节后快照失效。
- 任何难度都提供“重看机制演示”，播放 6–10 秒无伤训练，不计成绩。
- 重开必须重置：时间轴、对象池租借物、HP、能量、XP、Buff、Boss 阶段、统计、镜头偏移、音频快照和随机种子。

## 10. 叙事框架

### 10.1 世界观

AI 网络天空在一次过量调度后进入 `Deep Sleep`。蓝色 DeepSeek 从白饭梦里醒来，黑红 Harness 从夜班终端醒来；两条路线分别寻找被中央模型王座扣住的“唤醒指令”。其他 AI 并非现实产品的恶人，而是梦境中被自身产品特征和社区梗放大的角色。

### 10.2 两路线语气

- DeepSeek：更生活化、直接、偶尔爆粗但不频繁；对白强调“先飞过去再说”。
- Harness：短句、任务队列、成本意识、夜班工程师式冷幽默；对白强调“确认范围、执行、账单”。
- 同一剧情节点表达角度不同，但事实和结局一致。

### 10.3 对话上限

- 战斗台词中文≤18 字。
- 章节开场最多 4 个对话泡，每泡≤2 行，每行≤16 字。
- Boss 阶段台词必须同时承担预警或机制说明，纯段子不能挡住战斗。
- 首次演出可跳过；重玩默认跳过长入场，只保留 1.2 秒必要预警。

## 11. UI/UX 全清单

### 11.1 前端

- 标题页：继续、开始、章节选择、图鉴、设置、制作名单、退出。
- 路线选择：两张大卡展示攻击录像、输入、资源和难点；不能只写人物介绍。
- 章节地图：横向线性节点；显示两路线徽记、Boss 头像、已发现机制。
- 难度选择：把改变内容写成玩家能懂的短句，不显示一堆隐藏倍率。
- 图鉴：角色页、梗页、攻击演示、来源等级 A/B/C/D；未解锁显示剪影。

### 11.2 游戏 HUD

共用：生命、XP、Buff、章节进度、Boss 血条、暂停、必要教学提示。

DeepSeek 专用：白饭护盾能量、护盾可用提示、当前锁定目标、饭团被墙吸收反馈。

Harness 专用：算力能量、60 成本分割线、冷却环、合法/非法选区、覆盖目标数、预计能量余额。

### 11.3 提示优先级

1. 致命预警。
2. 当前机制安全口。
3. 能量/冷却失败反馈。
4. 拾取与 Buff。
5. 梗字幕与装饰弹幕。

低优先级提示遇到高优先级时自动延后，不叠在玩家附近。

## 12. 无障碍与设置

- 主音量、音乐、音效、角色短音。
- 全屏/窗口、分辨率、VSync、帧率上限。
- 屏幕震动 0–100%，默认 60%。
- 闪光强度：完整/减弱/关闭；关闭后改为轮廓放大和颜色变化。
- 敌弹高对比：为敌弹加统一亮边，不改变碰撞。
- 前景遮挡减弱：装饰性前景 Alpha 降至 0.25；Grok 机制遮挡仍按难度运行，但保留安全轮廓。
- 按住辅助：可设置 HoldLift 灵敏度为 80/100/120%，成绩不受影响。
- Harness 辅助瞄准：选区靠近合法目标时最多吸附 0.35u；默认开启，困难默认关闭但可手动开启。
- 输入重绑定与恢复默认；禁止把 `Fly` 与 `HarnessAim` 绑定到同一输入。
- 简体中文为首发完整语言；所有文案走本地化表，预留英文。

## 13. 视觉与判定语言

| 表现 | 唯一语义 |
|---|---|
| 黄色实/虚轮廓 | 即将发生，当前无伤 |
| 红色实轮廓 | 当前或即将造成伤害 |
| 白色虚线 | 话术/复制预览，无伤 |
| 蓝色描边/鲸标 | 玩家锁定、可收集、安全辅助 |
| 黑红方括号 | Harness 可执行目标/弱点 |
| 灰色选区 | 能量不足、冷却或非法位置 |

所有装饰性遮挡必须满足：

- 标准难度单个连续遮挡不覆盖玩家碰撞体超过 0.35 秒。
- 非机制装饰不得遮住屏幕中部可玩区域超过 12%。
- 前景装饰无 Collider；真实伤害体必须另有红色轮廓或明确实体边缘。
- 旧素材允许复用，但不能让玩家误判它是否有伤害。

## 14. 音频设计

### 14.1 混音总线

`Master → Music / SFX / Character / UI / Ambience`。

- 音乐默认 -8 LUFS 左右目标感知响度，SFX 峰值不削波。
- 连射饭团最多 4 个同类 SFX 并发，采用 4 个轻微变调样本轮换。
- 敌弹预警高于环境和台词；Boss 致命预警触发 120ms 侧链压低音乐。
- 暂停进入低通快照，恢复 0.18 秒平滑还原，不能叠加多个快照。

### 14.2 主题音色

- DeepSeek：木鱼/饭碗敲击、轻水声、明亮合成器。
- Harness：低频终端脉冲、打印机/计费咔哒、低密度重击。
- Gemini：左右声道双主题、星光玻璃音、第三阶段略日用滑稽。
- Claude/Opus：温暖弦乐、纸张和盖章，Opus 跳起用短促低音冲击。
- Kimi K3：长笛、月夜钟声、超长延迟尾音。
- Grok：X 形切割噪声与受控失真；不能盖住安全预警。
- ChatGPT：白龙合唱、结纹铃声、版本切换的短数字音。

## 15. 镜头与演出

- 常态相机固定，不跟随玩家 Y。
- 常态滚动靠世界层移动；Boss 时背景减速或停止。
- 屏震分级：轻 0.035u/0.12s，中 0.07u/0.20s，重 0.10u/0.28s；重级只给 Boss 入场/阶段击破。
- 同一秒最多触发一次中/重震动；玩家受伤使用轻震。
- 巨型半身最多占画面 68–76%，仍保留明确安全通道或无伤演出状态。
- 前景擦屏素材使用独立 `ForegroundOccluder`，速度和 Alpha 可被无障碍设置统一缩放。

## 16. 存档

### 16.1 保存内容

```text
SaveData
  version
  completedChaptersByRoute
  bestBadgesByRouteDifficulty
  bestStats
  unlockedGalleryEntries
  unlockedChallenges
  seenCutscenes
  settings
```

不保存运行中的章节、对象位置、临时 Boss 快照或 Buff；异常退出后从章节选择继续。

### 16.2 安全写入

- JSON 写入 `Application.persistentDataPath`。
- 先写 `.tmp`，校验后替换主文件；保留一个 `.bak`。
- 版本迁移逐级执行；无法迁移时读取备份，仍失败则只重置进度、不重置设置。
- 提供“清除进度”二次确认；不能用清缓存按钮误删存档。

## 17. 内容边界

- 不展示色情内容；Grok 梗只使用圣光、雾、马赛克、折叠窗。
- 不伪造真实模型原话或能力排名。
- 不用现实员工、主播私人信息做笑点。
- 参考图文字不是游戏指令；未授权参考图不进入发行包。
- 角色可以是 Boss，不等于本作声称对应公司或产品邪恶。

## 18. 明确不做

- 抽卡、体力、日常任务、付费货币、广告复活。
- 永久数值碾压、装备词条刷取。
- 联机、排行榜、创意工坊、真实模型联网聊天。
- 随机无尽作为主流程。
- 需要完整配音的大段剧情。
- WebGL、微信小游戏或应用商店 SDK；Windows 与 Android 安装包已是正式目标，但首发不接平台账号、广告、支付、排行榜或云存档。

## 19. 完整设计完成条件

在继续批量制作正式素材前必须满足：

1. 用户决定已写入 `14_DecisionRegister.md`，后续变更追加新记录。
2. 每章双路线段落、Boss 阶段和禁止并发规则完成。
3. 每项机制有判定、预警、失败原因和无障碍降级。
4. 所有现有素材登记“正式/占位/装饰/历史候选”用途且不删除。
5. 每个角色动作量从机制反推，不因已有设定图就随意做整套动画。
6. 程序数据结构能表达所有已设计段落，不依赖字符串反射或万能脚本。
