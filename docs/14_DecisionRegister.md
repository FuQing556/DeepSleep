- 日期：2026-08-31

- 后果：每章拥有 `DS` 与 `HA` 两份时间轴、资源和 Boss 解法；飞行物理共用。

## DR-002｜基础飞行输入

- 后果：Press 冲量和 Hold 升力分开实现。

## DR-012｜Neuro

- 日期：2026-08-31
- 决定：不得遗漏 Neuro；与 Evil Neuro 作为独立隐藏 Boss 关，尊重官方角色视觉和人格，不混入普通大模型强弱阵营。

## DR-013｜Unity 实施职责与零隐式装配

- 日期：2026-08-31
- 决定：用户负责全部 Unity Editor 操作；Agent 负责 C#、测试、配置类型、验证器和素材生成，并逐步提供详细装配说明。
- 决定：玩法数据不得硬编码在运行时代码；代码不得自动 `AddComponent`、使用 `[RequireComponent]`、创建缺失 GameObject/组件或自动修改场景、Prefab、配置资产。
- 影响：所有依赖显式序列化/初始化，所有数值来自配置；每轮只做一个可验证小步，用户在 Unity 验收后才进入下一步。完整规则见 `agent.md`。

## DR-014｜Windows + Android 双端与首发分发

- 状态：**平台与分发部分保留；“本地单机首发、暂缓联网”已由 DR-020 取代**。
- 日期：2026-09-02
- 决定：正式目标为 Windows x64 与 Android 横屏本地单机；从工程第一步就保留触控、多指输入、Safe Area 与宽屏适配。
- 决定：首发产物为 Windows ZIP 和签名 APK，可通过 GitHub Releases、粉丝群文件及国内网盘镜像直接下载。
- 暂缓：WebGL、微信小游戏、TapTap/4399 平台 SDK、账号、广告、支付、排行榜与云存档；这些都不是当前架构依赖。

## DR-015｜一状态一张角色主图

- 日期：2026-09-02
- 决定：角色、Boss、吉祥物默认每个语义状态一张透明主图，悬浮、摆动、后坐、闪色、淡入淡出等由 Unity Transform/颜色曲线与独立 VFX 完成。
- 后果：2026-09-02 之前的 6–12 帧动作预算全部撤销；八帧 DeepSeek 试验稿只保留为分镜历史，不进入正式 Sprite Sheet。
- 例外：只有实机证明单图无法把玩法动作讲清楚时，才为该动作追加最少关键帧，并回写 `06_ArtAssetManifest.md`。

## DR-016｜循环背景硬验收与旧背景降级

- 日期：2026-09-02
- 决定：横向滚动背景必须首末列逐像素一致、首尾至少 16px 同带，并提供两张原尺寸副本并排预览；“看起来很宽”不算循环图。
- 后果：旧 `BG_Far_AICloud_v01`、`BG_Mid_DataCloud_v01`、`BG_Near_Network_v01` 全部保留但标为 `DECOR_ONLY`，只用于菜单、章节卡或无碰撞静态装饰。
- 新资产：`BG_P0_Far_DataSky_Loop_v01.png` 已通过离线像素检查，等待 Unity 双副本滚动验收后转 `PRODUCTION_ACTIVE`。

## DR-017｜状态切换单残影

- 日期：2026-09-02
- 决定：角色切换语义状态时，新状态立即完整显示；上一状态复制到唯一的残影槽，立刻降至低透明度后淡出。残影不排队、不实例化、不允许同时存在两张以上。
- 默认表现分级：飞行状态约 0.15–0.22 秒，技能约 0.25–0.40 秒，大型转阶段/传送约 0.6–1.0 秒；普通受击改用闪色和抖动，不产生残影。所有具体值来自视觉过渡配置，不写死在代码中。
- 后果：Prefab 由用户显式装配 Current/Ghost 两个 SpriteRenderer；新切换覆盖仍在淡出的 Ghost。该效果只属于表现层，不改变物理根、碰撞体、输入响应或玩法状态时序。

## DR-018｜横屏合作射击取代扑翼双路线

- 日期：2026-09-04
- 决定：项目保持横屏横向卷轴，但核心改为雷霆战机式合作射击和可见火力成长；角色在屏幕内自由二维移动，不再使用点按扑翼、重力下落和上下夹缝作为主循环。
- 决定：DeepSeek与Harness始终同时出战，不再分别进入两条独立关卡路线。
- 后果：旧 `Flap` 输入、飞行物理、双路线时间轴和路线选择界面退出实现权威；原有背景、障碍、气泡和事件素材保留并重新安排用途。

## DR-019｜双鲸职责差异与合作闭环

- 日期：2026-09-04
- 决定：DeepSeek是高频自动索敌的常态火力核心，拾取后射速更快、弹道更多、弹体更大；饭团仍会被真实障碍阻挡。
- 决定：Harness常态火力明显较弱，主要使用受预算限制的手动范围技能清除可清弹，并对区域造成穿过普通障碍的高额爆发。
- 决定：Boss必须提供“蓝鲸持续压制→黑鲸清弹制造窗口→双方爆发”的合作节奏，不能把两个角色设计成换皮武器。

## DR-020｜单人AI与跨端双人联机

- 日期：2026-09-04
- 决定：单人先选一个角色，另一角色由本地AI接管；AI、真人和远端玩家使用同一角色命令与战斗规则。
- 决定：双人每台设备控制一个角色且不可重复，支持Windows↔Android、Windows↔Windows、Android↔Android。
- 决定：私人房间允许房主先选角色并分享房间码，加入者选择剩余角色且准备前可交换；快速匹配先选角色，只匹配选择另一角色且版本兼容的玩家。
- 决定：首版不做同设备双人、四人联机、竞技、聊天、公会和主机迁移。客人断线由AI接管；房主退出结束房间。

## DR-021｜联网与热更新纳入正式架构

- 日期：2026-09-04
- 决定：双人采用房主权威结构；客户端上传命令，房主裁决伤害、敌人、Boss、掉落、消弹和章节状态。
- 决定：资源热更新进入正式开发计划；C#代码热更新预留程序集和契约边界，在联网纵切面稳定后接入。
- 候选：Netcode for GameObjects + Unity Transport；YooAsset资源管理；HybridCLR代码热更新。具体版本必须在Unity 6.6新工程中逐项验证锁定。

## DR-022｜新建Unity 6.6工程

- 日期：2026-09-04
- 决定：停止在Unity 2022.3旧工程上新增玩法代码，使用Unity 6.6（6000.6.0f1）新建干净2D工程，不做原地升级。
- 原因：Unity Hub和官方发布策略将6.6列为面向新项目的推荐正式受支持版本；本项目尚未开始实现，关键第三方包又会在后续单独验证，因此不必为了尚未接入的依赖预先停留在6.3 LTS。
- 决定：新工程选择通用二维（Universal 2D）模板和URP 2D Renderer，为弹幕、二维灯光、圣光/迷雾、Shader Graph与Boss屏幕演出提供统一渲染基础。
- 原因：旧工程尚无玩法代码/Prefab，旧输入已失效，重建成本低于携带旧包和旧配置继续升级的维护成本。
- 后果：旧目录完整保留作档案；新工程不复制旧Library、Packages、ProjectSettings、Input Actions和程序集定义，只在后续逐项迁入文档、参考素材和经确认的生产资产。

## DR-023｜保留全部已有素材

- 日期：2026-09-04
- 决定：玩法改版不删除已有角色、背景、山体、气泡、障碍、VFX和候选图。
- 后果：旧扑翼状态图可重映射为漂移、闪避、受击或演出；不循环背景继续用于菜单和章节卡；小山、气泡等可作为遮挡、前景或事件装饰。

## DR-024｜独立资源、共享经验与中立道具争夺

- 日期：2026-09-04
- 决定：DeepSeek与Harness的角色技能资源、能量和火力配置相互独立，不能由队友直接消耗。
- 决定：击杀与收集产生的升级经验由全队共享；达到升级节点时两名角色各自从本角色池选择一次强化。
- 补充：每次强化固定为本角色卡池三选一；生命上限进入生存类强化池，并影响按最大生命计算的复活生命。
- 决定：有限回血“大米饭”、防御道具“不锈钢盆”和部分中立战术道具由实际拾取者获得，允许两名玩家争抢。
- 公平规则：满血角色不能消耗回血物；防御状态已满时不能浪费同类防御物；同一权威模拟刻同时触碰时，回血优先给生命比例更低者，其他道具按稳定槽位顺序裁决并提供明确反馈。

## DR-025｜章内重置与局外侧选解锁

- 日期：2026-09-04
- 决定：每章从角色基础形态开始，Token等级、局内火力、临时战术物和词元债在章节结束后重置；Boss前应能形成接近完整的本章构筑。
- 决定：通关获得的局外“鲸元券”只解锁带交换条件的起始协议、外观、图鉴、音乐和挑战合同，不购买永久攻击、生命、能量等纵向数值。
- 后果：后续章节不需要按“玩家必然满级”反向膨胀敌人数值，也不会因联机双方存档进度不同而形成基础属性碾压。

## DR-026｜模型宕机、热重连与AI化经济名词

- 日期：2026-09-04
- 更新：角色生命耗尽称为“模型宕机”，固定在倒地位置显示专用睡眠姿态。存活队友进入以倒地角色为中心的圆形范围并停止主动操作0.2秒后自动开始热重连，不再使用独立按键或可移动故障核心。
- 更新：移动、主动攻击、技能、受击和离圈都会中断并清空进度，但用于中断的主动操作必须正常执行。标准热重连持续2秒，完成后恢复`max(1, floor(最大生命值 / 3))`生命并获得1.5秒无敌。
- 决定：真实网络断开先由AI接管，不等于角色模型宕机。
- 决定：共享章内经验显示为`Token / 词元`；“词元债”表示主动透支额外拓展产生的风险与偿还目标；“鲸元券”是游玩获得的局外解锁货币。三者不得再衍生出多套同功能货币。
- 更正：用户于2026-09-04将先前误写的“字元债”更正为“词元债”；名称关联现实Token（词元）算力工厂科创债，游戏内不再使用“字元债”。
- 后果：现有`Reconnect`命令字段暂不承担玩家按键语义，后续清理输入资产时再统一迁移；Boss和事件需要救援兼容弹型；局外商店不得接入充值、广告兑换或永久数值售卖。

## DR-027｜王冠寻回主线与时代切面暂存

- 日期：2026-09-06
- 决定：远期剧情核心暂定为 DeepSeek 的“鲸鱼王王冠”失窃，她与妹妹 Harness 在数据空间中寻找王冠；偷窃者、动机、王冠含义和结局尚未锁定。
- 决定：数据空间同时容纳 AI 角色、数据垃圾和跨时代回忆。保留四个重点切面：充满希望的旧时代城市记忆、疫情时期国内大封闭、当下失望膨胀与 AI 加速并存的大娱乐时代、以及太阳人/月亮人/地球人/地底人分层的“假未来”。
- 角色种子：ChatGPT“高高在上”；智谱是 DeepSeek 好闺蜜并使用 08/13 与 08/14 组成“1314”的更新日期梗；Grok 使用圣光；豆包产生“我直接给你最XXX”式话术垃圾。
- 边界：当前只记录主题与取材，不改变核心战斗开发顺序，不锁定这些切面的关卡顺序；待基础玩法闭环后另行完成剧情结构设计。
