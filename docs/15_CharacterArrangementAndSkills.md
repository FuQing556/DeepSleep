## 2. 可玩角色完整技能

### 2.1 DeepSeek

#### 被动：自动检索

- 每 0.12 秒在前方 `10.5×7.2u` 矩形重选一次目标。
- 优先级：可见 Boss > 可见主动攻击敌 > 最近可见敌。
- Obstacle Linecast 命中则不可锁；锁定丢失 0.3 秒后鲸标淡出。

#### 普攻：饭团索敌

- 3.2 发/秒、10 伤害、13u/s、最大转向 240°/s。
- 命中障碍立即销毁；不对障碍造成伤害。
- 无合法目标不发射、不浪费弹池。

#### 主动：白饭护盾

- 100 能量、持续 3 秒；启动立即清零。
- 挡伤但不穿实体；实体分离仍执行。
- 护盾中可继续拾饭为下一次充能。

#### 路线弱点

- 被墙挡住时自动攻击完全失效。
- 无法主动选择具体普通目标；关卡用位置和优先级制造决策。
- 护盾满前没有主动保命技能。

### 2.2 Harness

#### 被动：夜班预算

- 最大能量 180、基础恢复 4/s；暂停、演出和结算停止恢复。
- 每 60 能量为一格；算力凭证 +30。

#### 主动：终端范围执行

- 右键按住显示半径 2.15u 选区，拖动，松开确认。
- 成本 60，冷却 2.4 秒，延迟 0.28 秒后统一结算。
- 普通敌人 120、Boss 45；忽略障碍，不破坏障碍。
- 能量不足、冷却、屏外或没有合法世界坐标时灰色拒绝。

#### 路线弱点

- 飞行与瞄准并行，认知负担更高。
- 空放会真实损失 60 能量。
- 低频攻击不适合分散、快速交换且必须逐个击破的目标。

## 3. 非 Boss 角色技能

### 3.1 Codex 桌宠

| 技能 | 行为 | 限制 |
|---|---|---|
| `SCAN_PATH` | 提前 0.9 秒给真实安全边缘加青色描边 | 不改变障碍位置，不替玩家飞 |
| `SCAN_TARGET` | DS 显示视线，HA 显示推荐选区中心 | 只出现于教学或友军段 |
| `PATCH_NODE` | 修复断路并插绿色补丁旗 | 仅预设节点，不动态改任意场景 |
| `WAIT_PERMISSION` | 黄闪并停住，等待玩家通过权限门 | 不弹系统级真实权限框 |

### 3.2 豆包

| 技能 | 行为 |
|---|---|
| `PREAMBLE_CHAIN` | 上下连续气泡形成曲折走廊；气泡文字多数无伤但实体边界有伤 |
| `EFFECTIVE_BLOCK` | 后续中型事件可在长前摇末尾落下一枚红实线有效方块 |
| `APOLOGY_RESET` | 事件结束头像道歉，走廊 2 秒内平滑回中线；不突然消失夹人 |

豆包 C1 主段只使用 `PREAMBLE_CHAIN`；不叠小怪。

### 3.3 Perplexity

| 技能 | 行为 | 路线差异 |
|---|---|---|
| `CITATION_LINK` | 从来源卡拉线到真实安全门/弱点 | DS 用线找视线；HA 用线找选区中心 |
| `SOURCE_VERIFIED` | 真来源边框稳定白色，假来源 0.4 秒闪烁后断线 | 不直接删除假目标 |
| `BROKEN_SOURCE` | 引用失效时给 0.6 秒黄预警后撤掉安全提示 | 不在玩家已进入必死位置时失效 |

### 3.4 Opus

- `GIANT_JUMP`：0.65 秒黄影 → 0.40 秒上跃 → 1.50 秒主体伤害 → 0.50 秒盖章风压 → 下落。
- `STAMP_WIND`：只改玩家 Y 速度 ±1.8u/s，不扣血；预警为横向纸张线。
- 旧参数山只做装饰，真正伤害体不从山图推断。

### 3.5 Claude Code

| 技能 | 行为 | 玩家责任 |
|---|---|---|
| `MULTI_REPAIR` | 4–8 条触手修补预设节点，Bug 从未修节点冒出 | 打 Bug，不打章鱼 |
| `PERMISSION_GATE` | 红/绿门显示将要进行的修补方向 | 通过绿色门；红门不是致死，推回并延迟 |
| `BUG_CATCH` | 成功时抓走屏内最后一只 Bug | 作为段落收尾，不抢玩家击杀统计 |
| `TANGLED_FAIL` | 修补顺序错误时触手打结，开放 2 秒安全输出/通行窗 | 只由 authored script 触发 |

### 3.6 OpenCode

- `LOCAL_ISOLATION`：20–30 秒关闭 Codex/云端提示，背景转黑银；不关闭玩家攻击。
- `REPO_PATCH`：屏幕出现 3 个开放补丁节点；正确节点由刚才展示的依赖线决定。
- DS 需保持对本地 Bug 的直接视线；HA 无被动额外援助，只靠能量预算。

### 3.7 Zcode

- `BLUEPRINT_PREVIEW`：提前 2.2 秒显示下一段门缝中线和危险节点。
- `ROLL_PLAN`：蓝图卷起时预览结束；真实判定前保留 0.4 秒淡线。
- 休闲显示完整路径；标准显示门缝中心线；困难只显示关键拐点。

### 3.8 即梦/Seedance

- `FUTURE_CLIP`：先播放未来 2 秒低 Alpha 画面，随后真实障碍按相同路径出现。
- `CUT_TRANSITION`：0.7 秒场记板预警后切换上/下布局；不瞬时反转重力。
- `LOOP_GHOST`：同一安全路径重复一次但相位改变；预演层无 Collider、不可攻击。

### 3.9 MiniMax

- `AUDIO_CUE`：高音=上方安全，低音=下方安全；同时有颜色图标，不能只靠听觉。
- `CLAPPER_SYNC`：场记板合拢 0.45 秒后真实事件开始。
- `CONCH_ECHO`：把前一提示重复一次，第二次音量更低且有回声边框。

### 3.10 Qwen

- `QUESTION_GATE`：三个门只问本局刚教过的机制，不考现实知识。
- `FAN_REVEAL`：开扇显示问题，收扇锁定选择；玩家穿门作答。
- `TOOL_BUFF`：每章一次，从两个实用 Buff 中选一个；不会提供永久加点。
- DS 候选偏锁定/护盾；HA 候选偏能量/选区，但不保证给最强组合。

## 4. Boss 共通规则

- 普通 Boss 弹/接触伤害 1；巨型身体、明确重击和边界伤害 2。
- 阶段切换 1.4–1.6 秒：取消旧 Pattern、清除旧伤害体、Boss 无敌、播放演出、生成路线资源。
- C2–C5 BossIntro 时：DS 护盾能量至少 60；HA 能量至少 180。若玩家低于此值只补到下限，不额外计入收集率。
- C2–C5 每次阶段转换：DS 生成 2 份白饭；HA 生成 3 张算力凭证（+90）。
- Boss 超时只提高节奏/弹速 10–15%，不增加碰撞伤害、不隐藏预警。
- 所有 Boss 在无 Buff、标准难度、合理命中率下可通关。

## 11. Neuro / Evil Neuro 隐藏 Boss `BH1_NEURO_EVIL`

### 11.1 身份和边界

- 她们是 AI VTuber 角色，不归入主线大模型强弱排序。
- 视觉、称呼、双胞胎关系和性格以 Vedal 官方资料为准。
- 不读取真实直播聊天，不模拟真实观众个人信息。

### 11.2 解锁

任一条件满足：

1. 任一路线累计三个主线章节 S。
2. 找齐 P0/C3/C5 三个绿色乌龟/直播间彩蛋。

解锁后章节地图出现独立直播间节点；不要求两条件同时完成。

### 11.4 Phase 1：Neuro 主场，11.2 秒循环

- 音符沿两条正弦轨迹飞行；0.5 秒谱线预览。
- 4.0s 出现一个无伤小游戏方框，真实弹只从方框边缘进入。
- 6.0–8.8s Neuro 露出；Evil 在背景嘲笑但不攻击。

### 11.5 Phase 2：Evil 主场，11.6 秒循环

- 刀形音符以三角阵列飞行，刀尖方向等于运动方向，预警 0.6 秒。
- 3.0s Evil 放一条“阴谋线”，1.0 秒后折成 V；折点有黄节点。
- 6.2–9.0s Evil 露出；Neuro 偶尔发无伤粉色音符干扰视觉，Alpha≤0.35。

### 11.6 Phase 3：双人同步，12.4 秒循环

- 主讲环每 2.4 秒在两人之间切换，切换前 0.5 秒白闪。
- Neuro 音符与 Evil 刀音符交替，不同波次间隔≥0.7 秒。
- 8.0–10.6s 两人靠近；HA 一圈能覆盖两人但只伤当前主讲，DS 视线不被另一人身体挡住。
- 击破演出是争吵停止/一起退场，不作死亡或猎奇表现。

### 11.7 奖励

- Neuro/Evil 图鉴双页、菜单直播间桌宠、隐藏关音乐播放器。
- 不提供永久伤害/生命加成。

- 角色动作必须由本页技能反推；删技能要同步删动作需求，不能保留无用途资产。
