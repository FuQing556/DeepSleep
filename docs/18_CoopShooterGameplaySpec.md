# 18｜双鲸合作横版射击完整规格 v1.1

> 最后更新：2026-09-04  
> 状态：新玩法权威文档；移动和战斗数值等待灰盒手感测试  
> 适用模式：单人+同伴AI、双人在线合作；Windows x64 与 Android 横屏

## 1. 产品定义

《DeepSleep》是一款 2D 横屏横向卷轴合作射击游戏。蓝色 DeepSeek 鲸鱼娘和黑红 DeepSeek Harness 鲸鱼娘始终同时出战：蓝鲸用高频、自动索敌的饭团弹维持常态火力，黑鲸用低频、高耗能的大范围执行清除弹幕并制造爆发窗口。单人时另一名角色由本地同伴AI接管，双人在线时两名玩家各控制一名角色且不可重复选择。

旧版“点一下飞一下、松开下落”的扑翼飞行不再是玩法核心。角色改为屏幕内自由二维移动，不受重力影响；“中国人会飞”保留为世界观、台词、入场动作和飞行姿态梗。

## 2. 体验支柱

1. **双角色缺一不可**：蓝鲸解决持续输出与目标压制，黑鲸解决弹幕危机与爆发窗口。
2. **火力成长必须肉眼可见**：拾取强化后，射速、弹道数量、弹体尺寸、范围和特效逐步升级。
3. **合作不是同时开枪**：Boss 和事件必须不断制造“黑鲸先清场，蓝鲸后压血”或“蓝鲸持续命中，黑鲸抓窗口处决”的协作节奏。
4. **AI梗必须变成玩法**：豆包的话术是气泡走廊，Opus 是巨大半身跳起，Grok 的成人内容梗转译为圣光和迷雾；不能只靠对白说明。
5. **单人与联机同规则**：敌人、关卡、角色和伤害系统只实现一套；真人输入、网络输入和同伴AI最终都生成相同的角色指令。
6. **先可读，再华丽**：玩家弹、敌弹、预警、拾取和装饰必须依靠形状、颜色、描边和运动语言同时区分，不能只靠色相。

## 3. 游戏模式

### 3.1 单人合作

- 玩家先选择 DeepSeek 或 Harness。
- 未选择的角色由本地同伴AI控制。
- 玩家可在章节开始前调整同伴AI倾向，但不允许在战斗中频繁切换角色规避机制。
- 暂停会冻结整个本地模拟。
- 不要求联网，已下载版本必须能够完整游玩。

### 3.2 双人在线合作

- 房间固定两个战斗槽位：`DeepSeek` 与 `Harness`。
- 两名玩家不能选择相同角色；房主也不能绕过该规则。
- Windows 与 Android 使用同一联机协议并允许跨端组队；必须覆盖电脑↔手机、电脑↔电脑、手机↔手机。
- 每台设备只控制自己的角色，首版不做同设备双人。
- “快速匹配”先选角色再排队，只匹配选择另一角色且版本兼容的玩家。
- “私人房间”先创建房间并生成房间码；房主可以先占用一个角色，加入者选择剩余角色，准备前双方可以交换。
- 在线模式不因一名玩家打开设置或升级界面而单方面暂停；需要停战的选择发生在安全段并由主机统一推进。
- 私人房间是首个交付目标；快速匹配在公网房间稳定后接入。首版不做聊天、公会和长期账号成长。

### 3.3 联机入口

```text
主菜单
├─ 单人游戏
│  └─ 选择角色 → 另一角色由AI接管 → 章节选择
└─ 双人游戏
   ├─ 快速匹配 → 先选角色 → 等待互补角色 → 准备房间
   ├─ 创建私人房间 → 房间码 → 房主可先选角色 → 等待加入
   └─ 加入私人房间 → 输入房间码 → 选择剩余角色 → 准备房间
```

准备房间固定显示双方平台、网络状态、角色、章节、内容版本和准备状态。任何一方改变角色或章节后，双方准备状态都要重新确认，避免一方在另一方不知情时开局。

### 3.4 教学模式

- 使用单人合作规则。
- 分开教学移动、蓝鲸常态火力、黑鲸清弹幕、救援和共鸣技。
- 玩家选择任意角色后，系统仍必须让玩家看到另一角色如何完成自己的职责。

## 4. 画面、坐标与卷轴

- 逻辑玩法区保持 16:9，正交相机尺寸保持 `5.4`，即 19.2×10.8 世界单位。
- 关卡从右向左滚动，玩家可在逻辑玩法矩形内自由移动。
- 20:9 等宽屏只扩展无碰撞背景和装饰；敌人、弹幕、拾取和可交互对象不得生成在 16:9 逻辑区之外。
- 两名玩家拥有独立软边界，并设置最小可辨识间距提示；不使用彼此实体碰撞把队友卡死。
- 场景世界默认自然向左滚动；普通遭遇中的敌人、危险与拾取物叠加统一世界滚动速度，背景按层使用视差倍率。
- Boss 段由事件配置选择“定点停景”或“连续飞行”，不能把所有 Boss 写死为停景。固定舞台或不会飞的 Boss 可令世界滚动平滑降至零；ChatGPT 龙娘等移动战继续滚动。两种模式下玩家移动规则都不变。
- 远、中、近景继续使用横向无缝循环；现有不循环插画只作为章节卡、菜单或局部装饰。

## 5. 输入语义

输入资产最终应表达意图，不直接调用角色组件。旧 `Flap` 不迁入Unity 6新工程，新输入资产由用户在新工程中创建，代码不得自动修改。

| 动作 | 类型 | 用途 |
|---|---|---|
| `Move` | Vector2 | 自由二维移动 |
| `PrimarySkill` | Button | 当前角色主要主动技能 |
| `SecondarySkill` | Button | 防御、锁定或辅助技能 |
| `Aim` | Vector2 | Harness 选区、菜单指针或触摸世界坐标 |
| `ConfirmAim` | Button | Harness 开始/确认选区 |
| `CancelAim` | Button | 取消本次选区，不消耗能量 |
| `Reconnect` | Button | 宕机队友附近按住以执行热重连；无目标时不触发 |
| `Pause` | Button | 本地暂停请求；在线转为菜单请求 |

基础射击默认自动进行，不要求玩家持续按住开火。这样桌面和手机都把注意力放在走位与合作上。

### 5.1 Windows建议绑定

- 移动：WASD 与方向键。
- DeepSeek 技能：鼠标左键/空格和鼠标右键/左 Shift，两套键位均可重绑定。
- Harness 选区：鼠标位置瞄准，按下主要技能进入选区，释放确认；取消键独立。
- 手柄：左摇杆移动，右摇杆或屏幕方向瞄准，肩键/面键释放技能。

### 5.2 Android建议布局

- 左侧虚拟摇杆控制移动。
- 右侧技能按钮控制主动技能；Harness 按住技能按钮后拖动选区，释放确认。
- UI 使用 Safe Area，移动触点与技能触点按 touchId 独立归属。
- 触摸取消、移出按钮、系统手势打断时必须安全结束输入，不能误放技能。

## 6. 统一角色指令

所有控制源每个模拟刻只产生一份 `PlayerCommand` 概念数据：

- 移动向量。
- 主技能按下、保持、释放。
- 次技能按下。
- 瞄准世界坐标或方向。
- 取消瞄准。
- 当前命令序号和模拟刻。

真人本地输入、远端网络输入和AI决策都只负责生成命令，不直接改血量、能量、Transform、弹幕或Boss状态。

## 7. DeepSeek 蓝鲸鱼娘

### 7.1 战斗定位

蓝鲸是队伍的常态伤害核心。她在没有技能资源时仍能持续输出，自动寻找可攻击目标，但投射物会被真实障碍和Boss实体部件阻挡。她擅长清除小型敌人、维持连击、压制Boss暴露部位，不负责大规模消弹。

### 7.2 基础攻击：饭团检索

- 自动选择有效目标并持续发射饭团。
- 目标优先规则由配置决定，可包含：威胁等级、距离、屏幕内优先、玩家标记和Boss部位权重。
- 没有目标时沿前方射击，不在玩家身后反复转向。
- 饭团属于真实投射物，碰到障碍、可阻挡部位或敌人后按弹体配置结算。
- 自动索敌只决定目标，不保证命中；快速目标仍可躲开。

### 7.3 主技能：集中检索

- 玩家指定一个目标或Boss部位，在持续时间内把自动索敌权重集中到该目标。
- 提高常态火力的利用率，而不是制造另一个全屏爆炸。
- 目标消失或不可攻击时安全解除，不让子弹追踪已回收对象。

### 7.4 次技能：白饭护航

- 在蓝鲸附近形成短时护航范围，可保护自己与靠近的Harness。
- 护航主要抵挡少量漏弹或救援过程，不替代Harness的大规模消弹职责。
- 护航的耐久、范围、持续时间和充能来源全部由角色配置决定。

### 7.5 局内火力成长

成长节点采用可配置策略组合，以下是表现顺序而非代码常量：

1. 提高射速。
2. 单弹变双弹或增加平行弹道。
3. 增加扇形侧弹。
4. 放大饭团并提高命中反馈。
5. 获得有限穿透或命中后连锁检索。
6. 高阶形态把部分小饭团合并为巨型饭团，控制对象数量和视觉噪声。

不允许所有升级都只写“伤害+百分比”。每个主要升级至少改变弹道、尺寸、命中特效或声音中的一项。

## 8. Harness 黑红鲸鱼娘

### 8.1 战斗定位

Harness 是危机处理和爆发核心。她的常态攻击明显弱于蓝鲸，但能清除高危弹幕、穿过障碍伤害区域内敌人，并在Boss破绽期造成高额爆发。她必须管理“预算能量”，不能无条件连续清屏。

### 8.2 基础攻击：终端脉冲

- 自动向前或向当前威胁目标发射低频黑红脉冲。
- 用于保持反馈、补刀和积攒少量资源，不与蓝鲸争夺持续输出定位。
- 弹道简洁、频率低，避免与技能预警混淆。

### 8.3 主技能：清算领域

1. 按下进入选区，显示范围、能量消耗和是否可释放。
2. 保持并移动瞄准点；选区期间角色仍可移动。
3. 释放后锁定区域，经过明确前摇执行黑红鲸落/终端清算。
4. 先处理区域内可清除敌弹，再对敌人和Boss部位结算爆发伤害。
5. 攻击无视普通障碍遮挡，但不能绕过Boss明确标记的无敌状态。

可清除弹、不可清除弹、剧情弹和危险环境必须拥有不同视觉边框；不可清除弹不能在没有说明的情况下欺骗玩家。

### 8.4 次技能：预算回收

- 把成功清除的弹幕转化为部分预算能量、共鸣或临时增益。
- 回收有单次和单位时间上限，避免在密集弹幕中无限循环清屏。
- 空放或只命中少量弹幕时回报明显较差，鼓励等待高价值窗口。

### 8.5 局内火力成长

1. 增加领域半径或清弹上限。
2. 缩短选区确认与执行前摇。
3. 提高最大储能或增加一次储存次数。
4. 执行后产生延迟余波。
5. 单次释放可设置主区和较弱的副区。
6. 高阶形态变为横贯屏幕的黑红鲸尾扫荡或多段轨道清算。

Harness 的升级优先扩大决策价值，不单纯追求更高释放频率。满级仍应存在无法连续清屏的资源空窗。

## 9. 双鲸合作闭环

### 9.1 基础循环

```text
蓝鲸持续击杀与压血
  → 敌人进入弹幕/防御阶段
  → 黑鲸等待并清除高价值弹幕
  → 清弹制造安全区和Boss破绽
  → 蓝鲸集中检索完成持续压制
  → 双方积累共鸣并进入组合技窗口
```

### 9.2 共鸣系统

- 双方有效输出、清除高危弹、互相护航和完成救援都会增加共享共鸣。
- 无意义空射、对无敌目标输出和低价值消弹不增加或只增加极少共鸣。
- 共鸣满后任一玩家发起，另一方在确认窗口内响应；单人模式由AI按战术条件响应。
- 组合技同时提供安全区与集中输出，但不跳过Boss完整阶段。
- 共鸣值、来源权重、确认窗口和效果来自 `CoopResonanceConfig`。

### 9.3 角色互补验收

标准难度下必须满足：

- 只依靠Harness基础攻击会明显错过合理的伤害窗口。
- 不使用Harness清弹会使中后期高危段难以稳定通过，但不能造成无预警必死。
- 蓝鲸可以清杂但不能大面积删除敌弹。
- Harness可以创造窗口但不能长期替代蓝鲸主火力。
- 同伴AI能完成另一角色的最低职责，不能因为玩家选择不同角色而让单人模式难度失控。

## 10. 生命、倒地与救援

### 10.1 状态机与显示名称

角色生命耗尽称为“模型宕机”，不用普通“死亡/尸体”表现。状态顺序固定为：

```text
在线运行
→ 模型宕机（生成故障核心并开始重连窗口）
→ 队友执行热重连
→ 恢复在线（短暂无敌与低血量保护）
```

- 两名角色拥有独立生命、受伤无敌和宕机状态。
- 宕机后角色缩成可辨认的鲸鱼形“故障核心”，仍由原玩家以低速移动，可以发送求救标记，但不能攻击、用技能或吸收拾取。
- “模型宕机”属于玩法生命状态；真实网络断开必须显示为“网络掉线 / AI接管”，二者不得共用图标、提示和代码状态。
- 故障核心不会继续受普通伤害，避免倒地后被弹幕反复处刑；它仍受逻辑玩法边界约束。

### 10.2 热重连操作

- 通用输入增加 `Reconnect`。电脑默认候选为 `E`，Android 只在进入救援范围时显示“热重连”按钮；最终绑定由新工程 Input Actions 资产显式配置。
- 存活角色进入故障核心附近、按住 `Reconnect` 才推进重连，不能擦肩而过自动复活。
- 救援者仍可用移动输入在救援半径内微调位置，但主动技能与重连按键不能同时占用同一个触点。
- 离开范围、松开按键或受击会中断推进；标准难度下进度短暂保留后缓慢衰减，不因一次擦弹瞬间清零。
- 蓝鲸可以先开“白饭护航”再重连；Harness 可以先用“清算领域”制造安全区再重连。两种角色都能救人，但准备方式不同。
- 重连成功后恢复配置比例的生命、获得短暂无敌并保留本章已选升级；不免费填满技能资源、不凭空恢复不锈钢盆。
- 热重连会给予共享共鸣和明确的双方反馈，但不得成为故意反复倒地刷共鸣的收益来源；同一角色连续宕机的共鸣奖励递减或归零。

### 10.3 失败与难度

- 两名角色同时宕机，立即判定本次章节失败。
- 任一故障核心的“重连窗口”耗尽仍未恢复，也判定章节失败；否则存活玩家可以无限拖延，合作职责会失去意义。
- 休闲、标准、困难只调整重连窗口、所需持续时间、进度衰减和Boss救援编排，不改变操作语义。
- Boss和关卡事件必须定义 `RescueResponse`：一人宕机时不暂停战斗，也不立刻生成新的封屏必杀，而是切入仍有压力、但理论上可完成重连的救援弹型。已有弹幕不凭空消失。
- 在线客人真实断线时先由AI接管；只有被接管角色在战斗中生命耗尽，才进入上述模型宕机流程。
- 所有时长、范围、恢复比例、连续宕机抑制和难度倍率均由 `ReviveConfig` 与难度配置提供，不写在运行时代码中。

## 11. 敌人、弹幕与障碍

### 11.1 敌人职责

- **杂兵**：提供常态火力目标和资源来源。
- **炮台**：制造可被Harness高价值清除的弹幕簇。
- **护盾单元**：迫使蓝鲸切换锁定或绕到暴露角度。
- **干扰单元**：短暂影响索敌、瞄准或可见度，但必须预警。
- **精英**：组合两种已有行为，不通过纯加血制造难度。

### 11.2 弹幕分类

| 分类 | Harness能否清除 | 视觉要求 |
|---|---:|---|
| 普通弹 | 是 | 标准敌弹轮廓 |
| 强化弹 | 有消耗或次数限制 | 加粗边框和内核 |
| 不可清除弹 | 否 | 独特形状、持续警示 |
| 环境伤害 | 否 | 与弹体完全不同的区域预警 |
| 剧情/演出物 | 不参与伤害 | 不使用敌弹配色和碰撞反馈 |

### 11.3 障碍原则

- 障碍不再承担Flappy Bird式上下夹缝主循环。
- 保留实体数据墙、管道和气泡作为局部路线压缩、遮挡蓝鲸饭团或事件装饰。
- 任何强制通道都必须给两名角色留出可辨识协作空间。
- 豆包段可独占一段路程，不与普通敌人和额外障碍叠加。

### 11.4 AI黑话敌人组件库

这些是可复用行为组件，不要求每个都做成人形。关卡精英通常由“一个攻击源 + 一个走位压力 + 一个特殊规则”组成；前期同时启用两项，中后期最多三项，禁止把全部机制堆在一个敌人身上。

| 组件 | 可见行为 | 玩家解法 | 适合组合 |
|---|---|---|---|
| `429限流塔` | 按清晰节拍关闭火力通道并喷出排队请求弹 | Harness清排队弹，蓝鲸在限流间隙压塔芯 | 炮台、Boss阶段门 |
| `幻觉代理` | 复制多个会被自动索敌选中的假目标 | 打掉引用标记或观察真身受击反馈 | 检索干扰、精英护卫 |
| `引用缺失节点` | 给幻觉单位供能，自身几乎不攻击 | 蓝鲸锁定节点；击破后假目标显形 | 幻觉代理、知识图谱墙 |
| `上下文蠕虫` | 在场上拖出越来越长的历史记录带，压缩可走空间 | 优先打断头部；Harness可截断尾部垃圾 | 追击段、Kimi过载段 |
| `提示词注入器` | 生成带红色引号边框的假路标、假拾取和假指令牌 | 攻击引号锚点解除；绝不真的反转玩家按键 | 迷雾、幻觉代理 |
| `赛博垃圾团` | 大量生成低价值图文碎片，死亡后会再分裂 | 规避低价值碎片，等Harness集中清理 | 视频区、Vibe Coding区 |
| `安全审核墙` | 盖出“无法协助”挡板，阻挡蓝鲸饭团但不挡敌弹 | 蓝鲸打开放行节点，Harness可穿墙爆发 | Claude、ChatGPT章节 |
| `工具调用机` | 先显示工具名与范围，再执行抓取、移动、删除等场景操作 | 读预警换位，打断正在调用的工具臂 | Agent工厂、Codex/Claude Code |
| `MCP中继器` | 用连线把多个敌人的工具和护盾组合起来 | 先切断中继器，拆散组合能力 | Agent精英、小型Boss |
| `缓存未命中兽` | 玩家频繁切换目标时加速，持续命中同一目标后失速 | 蓝鲸保持集中检索，Harness在其失速时爆发 | 高机动精英 |
| `人工复核门` | 要求短时间击中真正危险的目标，误打假目标会关门 | 两人先辨真伪再集中火力 | 章节挑战、Boss破绽 |
| `YOLO执行体` | 跳过前摇连续执行高风险动作，自身也会过热露出核心 | 保守躲避第一轮，抓过热窗口反击 | 高难精英、隐藏挑战 |

假UI只允许出现在玩法世界层，并始终带统一的“注入红框”；不得覆盖真实HUD、伪造系统弹窗或偷偷改变真实输入。

## 12. 掉落与局内成长

### 12.1 所有权规则

- DeepSeek与Harness拥有各自的技能资源、能量和火力状态，队友不能直接花掉对方资源。
- 升级经验全队共享；任意队员击杀或拾取经验都会推进同一经验条。
- 达到升级节点时两名角色各获得一次本角色强化选择，不争抢升级次数。
- 回血、防御和部分中立战术道具由拾取者获得，允许争抢并形成临场取舍。
- 满血不能拾取回血物，防御库存/耐久已满不能浪费同类防御物。
- 同一主机模拟刻同时接触回血物时，生命比例更低者优先；仍相同时按稳定角色槽位裁决，不能依赖设备帧率。

### 12.2 掉落类型

- `SharedExperience`，显示名“Token碎片”：共享升级经验，任意角色接触都归全队。
- `BudgetPacket`，显示名“API额度包”：补充Harness预算能量；DeepSeek接触时转交Harness，不形成争抢。
- `SearchIndex`，显示名“检索索引”：补充DeepSeek集中检索/护航资源；Harness接触时转交DeepSeek。
- `BigRice`：有限的大米饭，恢复拾取者生命，属于中立争抢物。
- `SteelBasin`：不锈钢盆，为拾取者提供有耐久的防御效果，属于中立争抢物。
- `ResonanceShard`，显示名“共鸣缓存”：补充共享共鸣，任意角色接触都归全队。
- `TacticalArtifact`：罕见的中立临时道具，由拾取者获得，具体行为由道具定义决定。

掉落归属、磁吸范围、共享规则和价值均由配置决定。联机时掉落生成和归属由主机裁决。

### 12.3 强化选择

- 战斗段内只进行无需停顿的拾取。
- 共享Token条填满后记入一个“上下文拓展批次”；重大强化在下一个安全段的“上下文拓展站”结算。
- 每个拓展批次给双方各一次本角色强化选择：DeepSeek只能从蓝鲸池选，Harness只能从黑鲸池选；任何一方都不能花掉另一方的机会。
- 每次候选至少覆盖“武器形态 / 主动技能变化 / 生存或资源循环”三类中的两类，不能出现三个纯数值加成。
- 主机等两人确认后统一继续；超时后按玩家预设优先级选择，不能让一名掉线玩家永久卡住房间。
- 单人模式可以暂停并正常阅读说明。
- 强化只影响本局，不形成永久攻击、生命或能量碾压。

### 12.4 经济名词只保留三层

| 名称 | 层级 | 作用 | 是否跨章节 | 证据性质 |
|---|---|---|---:|---|
| `Token / 词元` | 共享局内成长 | 填充共享经验条，触发双方各自拓展 | 否 | 大模型真实术语；“烧Token”是社区常用表达 |
| `词元债` | 风险标记，不是可拾取货币 | 记录玩家主动透支的额外拓展，并生成偿还任务 | 否 | 取自现实“Token（词元）算力工厂科创债”，玩法规则为本作转译 |
| `鲸元券` | 局外解锁货币 | 解锁侧选协议、外观、图鉴、音乐和挑战合同 | 是 | 本作原创；鲸鱼娘与“元/券”的双关 |

共享经验和债务统一使用中国大陆语境的 `Token / 词元`；游戏内不再出现“字元债”。

### 12.5 词元债与透支拓展

- 玩家在上下文拓展站拥有正常选择，也可以主动选择“透支部署”：立即获得一次额外候选、额外升级或刷新机会，并增加个人词元债。
- 每笔债在下一战斗段生成可读的“催收协议”，例如击破指定精英、完成职责协作、在限制时间内取得足够Token或完成无误伤复核。
- 完成协议就清除对应债务；失败不会降低生命、伤害或技能能量，避免弱势玩家进一步滚雪球，只影响结算评级和个人鲸元券奖励。
- 债务数量有配置上限；教程不出现，休闲难度默认隐藏，标准难度在玩家解锁一次章节后开放。
- 队友能看到“对方正在偿债”和目标，但不能替对方确认透支。团队共同完成的协作目标可以计入双方贡献。

### 12.6 稀有战术物池

稀有战术物不形成背包，不要求玩家停下来整理；拾取后立即生效或占用一个清晰的单次槽位。首轮实现只选其中三种验证，后续按章节开放。

| 显示名 | 玩法效果方向 |
|---|---|
| `缓存命中` | 下一次角色主动技能降低资源消耗或缩短准备时间，表现为绿色命中条 |
| `回滚点` | 抵消下一次致命伤并把角色移回最近安全位置；不救已经宕机的队友 |
| `上下文压缩` | 清除无伤害视觉垃圾和已失效历史带，把其中有效部分转为少量角色资源 |
| `引用标记` | 短时间揭示真身、隐藏弱点和幻觉假目标，提升自动索敌可信度 |
| `MCP工具箱` | 临时召来Codex桌宠或Claude Code章鱼执行一次拾取、修盆或补丁支援 |
| `免费试用额度` | Harness短时间预算充足，结束后进入明确预警的短暂限流期 |
| `人工复核` | 自动否决下一次提示词注入或假拾取，并给出“已复核”印章 |
| `YOLO模式` | 一段时间显著提高输出和移动，但暂停不锈钢盆保护；属于主动高风险单次物 |

### 12.7 章节重置与鲸元拓展商店

- 每章开始时Token等级、局内升级、词元债和临时战术物全部重置；角色从可理解的基础形态重新成长，并在Boss前接近本章完整构筑。
- 章节结算给两名真人相同的团队基础鲸元券，来源为通关、协作目标和章节挑战；不按抢到多少大米饭或个人伤害分走队友奖励。
- 个人未偿词元债只扣个人附加评级/附加鲸元券，不扣队友基础收益。
- 局外“鲸元拓展商店”只售：互斥的起始协议侧选、技能表现皮肤、角色服装、头像名片、音乐、图鉴、幕后草图和挑战合同。
- 起始协议必须有明确交换条件，例如“蓝鲸双发但单发较小”“Harness范围更小但回收更快”；禁止购买永久攻击、生命或能量等级。
- 鲸元券只能由游玩获得，不接入充值、广告兑换或真实货币入口。

### 12.8 单章完整游玩节奏

标准主线章目标为10至12分钟，具体时间由 `ChapterPacingProfile` 配置。每45至75秒至少发生一次有意义的变化：新敌人组合、稀缺补给、上下文拓展、章节专属事件、精英或Boss阶段，不能连续数分钟只刷换皮小怪。

```text
入场与章节梗预告
→ 暖机杂兵：确认本章基础规则并获得首批Token
→ 第一组敌人组合：攻击源 + 走位压力
→ 稀缺补给抉择：大米饭 / 不锈钢盆 / 角色资源
→ 安全段：第一次上下文拓展，可选择是否承担词元债
→ 章节专属AI事件：豆包走廊、Opus跃起、Grok迷雾等
→ 精英组合：三项以内的复合机制与催收协议
→ Boss前补给与最后一次拓展
→ Boss三段合作循环：持续压制 → 危机清场 → 破绽爆发
→ 结算：评级、鲸元券、图鉴/协议解锁、重试或返回房间
```

一章内至少安排一次“谁拿大米饭/盆”、一次Harness高价值清场、一次蓝鲸持续压制、一次热重连或低血量救援压力的机会。救援不是每章强制演出的必倒剧情；关卡只提供可能性，不能为了展示系统强行打死玩家。

## 13. 同伴AI设计

### 13.1 AI不是作弊替身

同伴AI使用与真人相同的移动、能量、技能冷却、碰撞和救援规则。难度差异主要表现为反应延迟、危险预测范围、目标选择质量和技能保守程度，不直接免疫伤害或凭空获得资源。

### 13.2 通用决策层

1. 生存：避开即将命中的伤害区。
2. 救援：在风险允许时接近故障队友。
3. 角色职责：执行蓝鲸压火或黑鲸清弹。
4. 编队：避免长期遮挡玩家视野或抢占同一路径。
5. 拾取：优先获取适合自身或共享目标的资源。
6. 演出：在安全时保持角色性格动作，不干扰战斗。

### 13.3 蓝鲸AI

- 默认保持较安全的中后场，持续锁定最高价值目标。
- Harness制造破绽后立即集中检索Boss弱点。
- 队友救援时优先开护航，而不是追逐远处拾取。

### 13.4 Harness AI

- 不对零散低危弹频繁浪费预算。
- 优先清除会同时威胁两名角色或封死路线的弹幕簇。
- Boss破绽即将出现时保留至少一次可用爆发，具体保留规则由战术配置决定。
- 玩家倒地时优先清出救援空间，再靠近救援。

## 14. Boss合作模板

每个主线Boss至少包含下列三类阶段，但顺序和表现可以变化：

1. **持续压制阶段**：蓝鲸有稳定输出目标，Harness处理小规模弹幕并积能。
2. **危机清场阶段**：Boss生成高密度、可读且可清除的弹幕，Harness创造安全区。
3. **破绽爆发阶段**：清弹、破部位或事件成功后Boss暴露弱点，蓝鲸持续射击与Harness爆发同时获得高收益。

禁止设计只能由某个角色独占完成、导致另一玩家长时间无事可做的阶段。角色职责不同，但双方始终有可读任务。

## 16. UI与信息层级

### 16.1 战斗HUD

- 左侧显示DeepSeek头像、生命、护航资源和当前火力形态。
- 右侧显示Harness头像、生命、预算能量和清算领域储存状态。
- 中央上方显示Boss血条、阶段和破绽提示。
- 共享共鸣条位于两名角色信息之间，表达合作而非某人的私有技能。
- 在线状态只显示延迟、断线/AI接管和重连，不长期占据战斗中心。

### 16.2 可读性

- Harness选区不能遮住不可清除弹边框。
- 满级蓝鲸饭团允许合并视觉，但命中范围必须与图像一致。
- 敌弹密度升高时自动降低无关背景特效和装饰透明度，规则由可访问性配置控制。
- Grok迷雾关仍需保留玩家、危险边缘和必要HUD的最低可见轮廓。

## 17. 数值与配置归属

当前阶段只锁定职责和规则，不锁死手感数值。下列内容必须通过 ScriptableObject 或远程内容配置提供：

- 移动速度、加速度、减速度、边界和碰撞体。
- 生命、受伤无敌、倒地、救援和难度倍率。
- 所有武器射速、伤害、弹速、弹道、索敌、穿透、范围和能量。
- 共鸣来源、阈值、确认窗口和组合技效果。
- AI反应、风险权重、技能保留和编队位置。
- 敌人、弹幕、掉落、Boss阶段和章节时间轴。

运行时代码只实现稳定行为策略。每种配置必须有稳定ID、版本和校验规则；不得依赖Prefab名称或资源路径解析玩法含义。

## 18. 垂直切片完成定义

第一份可玩切片不要求整章美术齐全，但必须证明：

1. 两名角色在同一横屏战场自由移动，彼此不阻挡。
2. 蓝鲸自动饭团形成明显持续火力，黑鲸基础火力明显较弱。
3. 黑鲸可以手动选区、清除可清弹并造成范围爆发。
4. 一个灰盒Boss完整展示“持续压制→危机清场→破绽爆发”。
5. 单人选择任意角色，AI都能接管另一角色并完成职责。
6. 同一局可先用本机双输入调试，再换为网络远端命令而不改角色代码。
7. 拾取后至少有三档肉眼可见的火力成长。
8. 所有数值来自配置，缺少配置时明确报错并停止对应功能。

- 竞技、排行榜和反作弊对抗。
- 大世界、随机匹配、公会、聊天和付费。
- 生成式大模型实时控制同伴AI。
