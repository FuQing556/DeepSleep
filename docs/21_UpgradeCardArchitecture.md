# 休息节点强化卡架构

## 这一版的结论

“公共可用”不等于“全队共享”。强化分三层管理：

1. **公共角色卡**：DS、HS 都可能抽到同一张定义，但各自保存等级。例如 DS 的“数据压缩”不会提高 HS 的伤害。
2. **角色专属卡**：通过角色掩码限制，只进入 DS 或 HS 的候选池。
3. **Team 卡**：真正的队伍级效果只保存一份共享等级。当前首批卡没有投放 Team 卡，但底层已经支持。

每张卡的静态内容放在 `UpgradeCatalog`：编号、文案、可用角色、作用域、最大等级、效果类型和每级数值。局内等级放在 `PlayerUpgradeRuntimeState`，不会修改 ScriptableObject 资产。

## 节点规则

- 休息节点是可重复购买的 Token 商店，不是“一次性节点奖励”。
- 每买一次就重新生成下一组三选一；只要仍在节点且 Token 足够，就能继续购买。
- 每名角色每节点首次刷新免费，之后每次刷新消耗 5 Token。
- DS 与 HS 各自保存并消费自己的 Token 余额。
- 战斗中所有击杀只累计一份“本次战斗共同收益”；进入节点时，这个结算数完整地分别加入 DS 与 HS 的余额，不做对半分账。
- 当前不设普通/稀有/史诗等随机品质；重复选择同一张卡就是升一级，界面显示当前等级到下一等级。
- 联机时主机生成候选并验证刷新、选择与等级，客机只提交请求。
- 买不买、买多少都由玩家决定；购买不是离开节点的前置条件。

## AI 接管与构筑权

- 战斗控制权和构筑消费权彼此独立；AI 接管战斗不等于获得消费 Token 的权限。
- 单机由同一名玩家分别操作 DS 与 HS 的强化装置，AI 同伴不会自行购买。
- 联机时每名在线玩家只操作自己角色的强化装置；主动托管给 AI 后，玩家仍保留该角色的构筑权。
- 客机断线后，主机侧 AI 只负责战斗、救援和进入传送门，不刷新卡牌、不购买强化；它进入传送门后自动准备，避免阻塞仍在线的玩家。

进入节点时云层淡出以揭示神殿；离开节点时使用相同时长反向交叉淡化：神殿淡出、云层淡入。交互和商店在离场开始时关闭，滚动与刷怪只在淡化结束后恢复。

## 首批实际效果

| 卡片 | 卡池 | 每级效果 |
|---|---|---|
| 数据压缩 | DS/HS 公共角色卡 | 当前角色基础武器伤害 +15% |
| 运行时超频 | DS/HS 公共角色卡 | 当前角色基础攻击频率 +12% |
| 大饭团 | DS 专属 | 饭团伤害 +25% |
| 米粒风暴 | DS 专属 | 饭团发射频率 +18% |
| 终端增幅 | HS 专属 | 贯穿激光伤害 +25% |
| 冷却回路 | HS 专属 | 激光冷却速度 +18% |

公共卡基础价格为 12 Token、每个已有等级令下一次价格增加 3；角色专属卡基础价格为 15 Token、每级增加 4。

敌人只有在 `Defeated`（被击败）离场时才累计 Token，碰撞后消失、飞出边界或调试清场均不发奖励。1–5 Token 的概率依次为 `10% / 25% / 30% / 25% / 10%`，数学期望为每次击败 3 Token。中央 HUD 显示本轮累计；抵达节点后，DS 与 HS 左右状态栏分别显示各自余额。实体掉落物与吸附动画等到有正式 Token 素材时再接表现层，不改变奖励账本。

伤害和攻击频率采用“同类加法、最终一次乘算”：同类强化不会彼此指数膨胀。例如 +15% 与 +25% 合并为基础值的 1.40 倍。

## 扩展边界

`UpgradeEffectKind` 已为束宽、弹道数量和最大生命预留类型，但未把未完成机制伪装成已生效卡片。后续“大饭团溅射”“更多光束”“更多弹道”等需要各自的运行时结构和表现层，再加入目录。
