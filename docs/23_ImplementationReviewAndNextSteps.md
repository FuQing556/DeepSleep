# 当前实现复盘与下一步（2026-09-08）

本页记录工程事实与本次审查范围，替代旧交接的进度描述。玩法权威仍为 DesignSpec_v5 与 18；不能把规划当已实现。

## 已实现与职责

- 输入：Input/Commands 定义统一命令；Input/Local 适配 Input System；PlayerControlAssignment 按角色分配控制源。
- 调度：PlayerCommandDispatcher 先处理复活取消，再按行动限制分发，同帧操作能够中断救援并继续执行。FixedSimulationLoop 调度玩家命令及复活进度。
- DeepSeek：自动饭团、手动锁定/转身、弹体池、命中反馈及锁定标记。
- Harness：手动终端激光；控制器决定时序，快照工厂冻结几何，窄盒查询逐束去重，伤害执行器扣血，Presenter 分发表现。动态网格重复 UV，不拉伸整张位图。默认无贯穿衰减，各束独立结算。
- 敌人：404 为漂流一次性撞击物；机械蛇选最近有效玩家，追击、停下蓄力、红眼开火、后摇后恢复移动。敌人与子弹均池化；击杀、撞击与普通离场分流。
- 生命/救援：生命耗尽进入睡眠宕机；队友进入圆形范围并停止主动操作后引导；移动/主动操作/受伤中断并清空；复活血量按最大生命三分之一向下取整且最低1计算。行动、范围、进度和表现分开。
- 表现：按玩家/敌人来源区分命中特效倍率，治疗加号归玩家来源；子弹判定和死亡尺寸不受倍率控制。复活环独立，三层加号已扩散到半径1.65。
- 编辑器调试：DeepSleep > 调试 > 刷怪（停止全部刷怪、开始全部刷怪、清除敌人与敌方子弹），玩家（击倒 DeepSeek、击倒 Harness）。仅播放模式启用；场景搜索局限于 Editor 菜单。

## 下一轮建议切片

优先补 Harness 清算领域的首次可玩链：选区预览 → 合法性和预算判断 → 前摇 → 清除合格敌弹 → 范围伤害 → 消耗/冷却 → 完整视觉反馈。现有激光是普攻，不能用它代替主动技能。

实现前讨论：释放时冻结区域；清弹与伤害在哪个模拟时点结算；不可清弹如何表达；预算不足如何反馈。先核对当前圆盘/外圈/EMP素材的存在和规格，再决定需要补产哪些素材。参数保持显式配置，沿用用户调整过的碰撞体。

后续路线：主动清弹与预算 → 掉落和共享Token → 强化选择/火力成长 → 失败与重试 → 同伴AI → Boss纵切面。每次交付完整可验收切片并解释结构，避免重新做已完成系统。
