## 第二轮试玩修订：剑柄、3-4-3、尺寸与持续清弹（当前值）

2026-09-08。本节优先于下方历史验收记录。

- 剑柄使用激光的同一个 `LaserOrigin`，受角色朝向影响，不再绕角色中心转。剑图导入枢轴改到剑柄中心 `(0.15, 0.50)`，剑尖 X=0.985；原 PNG 未改。
- 待机剑角度 **-90°**，剑尖朝下，在发射节点附近上下轻浮。待机额外偏移归零，剑柄到剑尖长度0.6。
- 三招挥剑仍为 **0.5秒**，现为 **0.15秒长大 → 0.20秒保持 → 0.15秒缩小**（Grow=0.3、Shrink=0.3）；位移仍用立方曲线先慢后快，两种曲线互不混用。
- 每招剑气都用图内的一个对齐点，自动贴到轨迹末端的“完整长度剑尖”。剑缩小收回后剑气不会跟着缩回角色身上。`WaveOffset` 现在只作额外修正，不再是从角色原点猜位置。
- 上挑、横斩开启左右翻转，图片和多边形判定一起翻。下劈/上挑/横斩当前角度为135°/35°/-12°，世界图宽3/3/3.8；横斩不拉扁，按原图比例放大。
- 横斩的对齐点为 `(1/6, -0.055)`（以原图中心为0、两轴均按图宽计），翻转后对应靠角色一侧的约三分之一位置；位置仍可按视觉继续微调。
- 刀刃现在**整个挥剑过程中**查询敌人和可清除的敌弹，不再只能等末尾剑气清弹。固定模拟刻之间细分轨迹，用胶囊范围补扫；横斩扁轨迹也计入采样密度。不是遍历全部敌人，也不是整片扇形始终生效。
- 刀刃与剑气仍各自对同一敌人结算一次；剑气出现时查询一次，此后仅淡出。敌弹复用原 `TryClear` 与对象池，不生成命中特效。
- 以 HS 普通常态母图比对头部/躯干的视觉大小，而非头发、尾巴外框；只调等比显示与偏移。第一轮校准为：持剑待机0.95、下劈0.92、上挑0.94、横斩0.96。没有重画角色或调整碰撞体，仍可由用户试玩细调。
- 用户把测试持续时间改为 **10000秒**，本轮保留；退出冷却8秒、残影起始alpha0.55/淡出0.35秒、剑气淡出0.45秒。

### 最简单的调法

选场景中的 HS 根节点 → **Harness Melee Controller → HS 近战调节**，无需再寻找四份配置：

1. `预览动作` 选择下劈、上挑或横劈；`人物大小` 只改当前招的图片，持剑待机有单独一项。
2. `大剑长度（剑柄到剑尖）` 改刀长；剑气的贴合点会自动跟随。`剑气大小` 等比改变整张剑气和它的判定。
3. `剑气倾斜角度` 改倾斜；`剑气额外偏移` 微调位置，朝右时 X 正值向前、Y 正值向上；朝左自动镜像。
4. `长大占比/缩小占比` 当前均0.3，中间保持时间自动为剩下的0.4；不用填写三份秒数。
5. Scene 开启 Gizmos 和 `显示范围`：黄色点=剑柄，青色=刀刃轨迹，红色=剑气查询多边形。调人物图片不改变这些判定。

**这些参数直接写配置资产，Play 中修改也会保留。** 当前姿态缩放可即时观察；轨迹/剑气调整建议松开攻击再出下一刀，避免在一次攻击中途改规则。

## 直接试玩

当前 `Gameplay_Prototype` 的本地角色为 Harness（HS），沿用现有选角分配，不把角色永久绑定真人。

1. Play 后按 **空格**进入近战，并立即朝当前方向下劈一刀。
2. 按住 **鼠标左键**连续攻击，鼠标给出方向，不必点中敌人。
3. 顺序为下劈 → 上挑 → 横劈 → 循环。每刀开始锁定方向；中途移鼠标不扭曲正在挥的刀。
4. 松开会完成当前刀，然后停在近战待机。小剑在身前浮动。
5. 到期完成正在进行的一刀后回激光；倒地立即中止近战。

清场仍使用 `DeepSleep > 调试 > 刷怪` 的停止/清除菜单。

## 首轮确认的规则（数值变化见第二轮）

- 每刀默认 0.5 秒；前 10% 从小变大，中间 80% 保持大剑，末 10% 缩小。
- 位移进度默认 `t²`，先慢后快。时间过半时只挥过 25% 的角行程；它不改变大小曲线的平台长度。
- 剑是独立 Sprite，平移、旋转、等比例缩放。横劈通过扁椭圆轨迹及横向剑气表现，不拉扁剑图。
- 挥剑结束立即切近战待机并生成剑气。剑气只在出现时查询一次，此后仅淡出。
- 刀刃和剑气分开结算，同一敌人允许各吃一次。每段按伤害接收者去重，不按碰撞体数量累计，也不每帧重复扣血。
- 刀刃用沿轨迹细分的胶囊查询，避免高速剑尖跨过目标；不遍历场上全部敌人。
- 剑气使用每招独立的多边形查询，与该招剑气的平移、旋转、宽度和镜像一致。轮廓是基于亮弧的首轮手调，并非逐像素判定；内弧与剑尖的贴合程度仍待玩家视觉验收。
- 剑气清除范围内允许被清除的敌方子弹，通过原对象池回收。不清除怪物本体、不触发子弹撞击特效。
- 新动作立即显示，旧动作使用现有单残影机制随角色位移、保留旧朝向，再淡出。
- 近战待机不阻止救人；挥剑阻止开始救援。技能/攻击仍通过原复活预处理取消救援，然后执行动作。

同目录的 `CFG_HA_Melee_Down / Up / Sweep.asset` 分别配置三招：

- `Swing Seconds=0.5`，`Recovery Seconds=0.08`：收刀后短暂待机，再响应持续按住。
- `Travel`：角位移变速曲线，起止必须为 0/1、单调、先慢后快。
- `Start / End Angle`、`Orbit Height`：各招轨迹。横劈初值 Orbit Height=0.32。
- `Grip Radius=0.4`、`Sword Length=1.7`、`Blade Width=0.16`：剑与刀刃扫掠。
- `Blade Damage=2`、`Wave Damage=3`：测试伤害，不是最终平衡。
- `Wave Offset / Rotation / Width / Polygon`：剑气摆放及范围。Polygon 是以图中心为原点、图宽为 1 的坐标，Y 也按图宽计。

选中 HS 根节点，在 **Harness Melee Controller** 的检查器底部选择预览招式，在 Scene 中看青色刀刃轨迹和红色剑气边界。可直接点击“选中这一招的配置”。

角色、404、小蛇及其子弹原有碰撞体尺寸均未修改。剑、剑气不跟随“命中特效倍率”设置；成功命中的红晶闪光复用玩家来源倍率。

## 代码职责与装配

运行代码统一位于 `Assets/_Project/Scripts/Runtime/Combat/Weapons/Harness/Melee/`，没有第二套预制体目录或测试场景。

| 文件/对象 | 职责 |
| --- | --- |
| HarnessMeleeConfig / AttackConfig | 总参数、三招独立配置；游戏逻辑不修改这些资产 |
| HarnessMeleeController | 接收统一命令，保存形态/挥剑状态、当前招式、固定瞄准方向；固定刻推进 |
| MeleeSwordGeometry2D | 表现和刀刃判定共同使用的位置、尺寸、朝向计算 |
| HarnessMeleeDamageExecutor2D | 两套去重集合、扫掠查询、单次剑气查询、子弹回收 |
| HarnessMeleePresenter2D | 与激光明确交接姿态所有权，切角色图、残影、小剑和命中表现 |
| MeleeWaveView2D | 世界位置固定的剑气淡出，不负责伤害 |

`PF_Player_Harness.prefab` 新增上述三组件、`MeleeWaveQuery` 和 `CharacterRenderGroup/MeleeVisuals`。MeleeVisuals 内的小剑及 8 个预装配剑气槽位构成固定容量视图池；不临时添加组件，耗尽时有明确警告，伤害不受视觉池影响。

命令消费者顺序：近战控制器 → 移动 → 激光。开技能先交接表现所有权，再取消激光目标并抑制新激光输入，避免同帧同时攻击及抢贴图。已经射出的激光可自然播完。

`GameSimulation/FixedSimulationLoop.worldStepComponents` 已登记近战控制器：技能时钟不依赖鼠标是否有输入，失去命令源也不会卡住当前刀。连续攻击要求本刻确实收到按住命令，不能沿用旧按键状态。
