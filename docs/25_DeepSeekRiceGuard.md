## 用户确认的规则

- 圆心跟随DS，范围内DS和HS共享六次挡伤。
- 持续8秒；到期、次数耗尽或中止后冷却16秒；最后2秒闪烁。
- 圆不是拦截所有路过子弹的实体障碍。只有在圈内的玩家实际将要受伤时才消耗次数。
- 六碗饭显示剩余次数，沿圆周公转，各自自转；减少后平滑均分圆周。到期视觉淡出不延长保护。
- 米饭护航属于持续技能状态展示，不属于玩家造成伤害的命中特效，也不属于敌人命中玩家的特效；不得读取或响应两类 `CombatEffectScaleSettings` 倍率。它只使用自身表现组件的独立尺寸参数。
- 完全挡住的攻击不扣血、不触发受伤事件，也不打断救援。施放技能本身按既有主动输入规则中断正在进行的救援，之后可重新救援。
- 同次攻击多碰撞体/重复回调只消耗一次，不同弹体必须各自编号；不能把敌人ID当作攻击ID。
- 用户要求范围比当前治疗最大圈稍大。已核对两角色治疗圈最大配置直径3、父节点世界缩放1；初始护航直径3.45（+15%）、半径1.725。按角色根位置判断是否在圈内，独立可调，不修改原受击碰撞体。
- 环境与穿盾攻击资格需显式表达，不能默认所有伤害都可挡。

## 已完成代码

- `Runtime/Combat/Weapons/DeepSeek/Guard/DeepSeekRiceGuardConfig.cs`：次数、时长、冷却、预警、保护半径的显式配置。
- 同目录 `RiceGuardState.cs`：冻结配置中的时序/次数，管理展开、挡伤、耗尽、到期、中止、冷却。每次展开最多记录六个已挡攻击ID；即使最后一碗消耗，重复回调仍识别为已挡。
- `Editor/Diagnostics/RiceGuardStateChecks.cs`：瞬态测试配置，不改变场景；覆盖重复攻击、不同攻击、末次破盾重入、零ID、暂停、冷却、重新展开、到期预警、大步长跨到期、中止及配置快照。
- 参数资产：`Assets/_Project/Configs/Combat/DeepSeek/CFG_DS_RiceGuard_Default.asset`；当前值6 / 8 / 16 / 2 / 1.725。
- `DamagePacket` 现在显式携带一次攻击的 `AttackId` 和 `DamageInterceptionPolicy`。未声明的伤害默认不可拦截，避免未来环境伤害、剧情伤害被护航意外吞掉。
- `DamageAttackIdAllocator` 为每次实际发射/生成的敌方攻击分配非零ID。蛇弹每次从池中租出时换新ID；404类一次性接触攻击每次启用时换新ID。
- `PlayerDamageReceiver2D` 在生命值变化前询问已注册的 `IPlayerDamageInterceptor`。护航成功时不扣血、不开始受伤无敌帧、不广播 `DamageAccepted`，因此不会误触发救援中断。
- `DeepSeekRiceGuardController` 接收DS的 `PrimarySkill`，在固定模拟刻维护8秒有效期与16秒冷却；只保护半径1.725内、显式登记的DS与HS。DS倒地会结束技能并进入冷却。
- `DeepSeekRiceGuardSceneInstaller` 是幂等编辑器装配器。它只在编辑器中运行，用于把控制器接入DS命令消费者、双方受伤门和场景固定帧循环；运行时玩法不依赖MCP。
- `Gameplay_Prototype` 已完成上述引用装配，并保存到场景。
- 正式素材 `Assets/_Project/Art/VFX/DeepSeek/RiceGuard/SPR_DS_RiceGuardBowl_v01.png` 使用 512 PPU、Single Sprite、Bilinear、关闭MipMap、无损压缩导入；与DS角色母图使用相同画布和PPU基准。
- `DeepSeekRiceGuardOrbitView2D` 是独立表现组件。米饭没有Collider，不会用六个小物体重复做物理查询；表现异常不会改变挡伤结算。
- 正式法阵与破碎素材：`VFX_DS_RiceGuardCircle_v01.png`、`SPR_DS_RiceGuardBowlBroken_v01.png`。它们与饭碗统一使用 512 PPU、Single Sprite、Bilinear、关闭 MipMap、无损压缩；只负责视觉，不带 Collider。
- `DeepSeekRiceGuardCircleView2D` 根据轨道表现的 `OrbitRadius` 自动缩放法阵，使饭碗中心落在法阵可见外圈；初始逆时针 `18°/s`，与饭碗顺时针 `28°/s` 相反。视觉外圈和规则保护半径彼此独立，调整法阵不会暗改挡伤范围。
- 破碎初始表现值：定格展示 `0.3s`，随后缩小淡出 `0.4s`；破碎图因自身可见轮廓较大而使用 `0.88` 的尺寸校正，视觉目标仍是与完整碗近似等大。技能自然结束时完整饭碗淡出 `0.35s`。最后一碗耗尽仍保留完整破碎展示和淡出流程，不被结束事件截断。
- 播放模式调试入口：`DeepSleep/调试/玩家/展开 DS 米饭护航`。它与正常输入共同调用控制器的同一个施放门，不会绕过存活、展开中和冷却规则。`DeepSleep/调试/玩家/让 DS 护航承受一次攻击` 会通过真实 `PlayerDamageReceiver2D` 伤害入口送入一次可挡攻击，用于检查扣碗、破碎和重新均分，不直接修改剩余次数。
