# 战斗强化版本：2026-09-13

本文覆盖 docs/29 第4—6节的早期草案；以下为本次实际实现与可调参数，不是后续模型自由发挥的建议。

## 本次规则

- 生命和伤害整数化：HS初始激光3，DS饭团1，角色生命3。正伤害在最终DamagePacket入口向下取整，最少1；零伤害仍为0，护盾/无敌不会冒正常伤害数字。分支的中间倍率不提前取整。
- 生命强化每级上限+1，活着补1，倒地不因此复活。两角色分别记等级。节点失败回滚沿用原快照，消费仍各花各的钱。
- DS弹道从同一炮口发散，60度扇区内等分，按各扇区中心发射（5发相对中心为-24/-12/0/12/24度）。多目标校准在各弹道8度内寻找不同目标，不额外生成子弹，无目标保留原方向。
- HS弹道+1就是多一个独立可见发射装置。炮口沿瞄准方向的垂线分布，间隔0.75世界单位；各自瞄同一目标，越过目标仍贯穿，各束独立结算。第二、三层网格宽度分别为束身1.15/1.4倍，在BeamTiledMeshView2D模板中配置，仅调整表现宽度。
- HS连射每级多一轮完整齐射，轮间隔0.18秒，一次校准，最后一轮才开始原冷却。目标消失仍按最后瞄准点完成；有可用替代目标时后续轮可换目标。取消、倒地、切近战、进入节点或失败时取消尚未发出的攻击。
- 连锁0级：主束1层。连锁1级：主束2层，一级分支1层。连锁2级：主束3层，一级2层，二级1层。束身/过载/外框是独立纹理通道，不是换色或用缩放冒充层数。
- 各束实际命中的每个敌人可成为分叉源；从其碰撞体中心检索下一跳，一级2.5、二级2.0世界单位；每跳伤害×0.5，三级均贯穿。排除当前源与该分支祖先作为锁定目标，优先尚未被同级其他分支预定的候选。几何额外覆盖仍独立结算。
- 单次齐射包含主束在内最多128条，超过会警告；连射各轮独立冻结世界快照与淡出时间。束体与炮口复用预制体内的模板并缓存复用，不在渲染层重算伤害。

## HS近战：必须保持的约束

- 近战不发生激光连锁。
- 初始武器范围为已确认动作配置的1.15倍；两级范围强化为1.15×1.30=1.495倍。
- 同时缩放剑长、剑柄轨迹位移、剑气大小/偏移、刀刃和剑气碰撞。角色CharacterScale/Offset不参与强化。独立小剑使用相同武器倍率。
- 连射强化对应近战整套动作时钟：挥剑、收刀、人物动作切换、跟随收势、残响延迟、剑气/残影淡出共同加速。技能持续时间、技能冷却不受此倍率影响。原动作各阶段曲线不改成固定343。
- 刀刃基础2，主剑气3；攻击强化按上表增长。刀刃扫掠期间去重，主剑气出现瞬间判定；刀刃与剑气分别计伤。
- 残响延迟0.10/0.20秒除以动作速度，分别造成主剑气50%伤害；各自一次命中，不再次清弹，不连锁。
- 残响保留本刀结束时世界原点，使用同动作剑气；下劈每次偏-6度，上挑/横劈+6度，并向外偏0.12/0.24个当前剑长。对应碰撞随相同几何变化；不重新驱动人物动作。
- 配置入口：`Configs/Combat/Harness/Melee/CFG_HA_Melee_Default.asset`；各动作的Echo Angle Step可独立调。

## 验证事实

从Boot→主菜单→单人→选择HS进入运行场景，用冻结模拟时间的测试步骤验证：

1. HS损失1血后购买生命卡得到3/4；DS仍3/3。
2. 3炮口×3轮齐射，每轮测试布局得到3主束、6一级分支、8二级分支；完成后Cooldown，束体淡出后可见通道0。
3. 目标在校准完成前全部回收，仍发3轮，连锁未解锁时主束1层，结束无残留瞄准。
4. 三个近战动作均得到范围倍率1.495、时长倍率0.7692308、角色配置倍率1；原动作资产的轨迹没有被运行时修改。
5. 一刀主剑气+两次残响共3个事件，基础显示伤害3/1/1。主动退出近战后恢复激光。
6. DS满级5发，角间隔12度，每发6伤害；额外购买满级弹道返回false。1.5→1，0.75→1，0→0。
7. 协议2的128束快照序列化4889字节，往返束数/起点/层数/分支标记/伤害一致，在现有16384字节上限内。
8. 一刀已完成但残响尚未发出时触发战败暂停，后续残响事件0、近战退出、瞄准清空；只封锁战斗命令，不封锁节点移动。最终启动回归控制台0 Error/Warning。
