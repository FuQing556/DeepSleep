# 局内菜单与局域网发现

更新日期：2026-09-13。范围：战斗菜单、单人托管、联机大厅；不替换商店/强化卡美术，不改战斗判定。

## 玩家流程

- 单人选角后，顶部显示「菜单」「AI 托管」。菜单暂停单人模拟；继续游戏恢复原时间倍率。AI 按钮直接交接当前角色，另一个队友不受影响；托管后按钮变为「收回控制」。
- 电脑 Esc 开关局内菜单；手机点击菜单按钮。菜单开启时屏蔽战斗输入，隐藏触屏战斗键。托管时隐藏战斗键，收回后恢复。
- 联机局内菜单不暂停房主或队友。退出战斗有确认提示；房主退出会断开队友。离开菜单不会偷偷取消托管。
- 联机大厅：一端创建 DS/HS 房间，另一端在同一 Wi-Fi/热点下等待房间列表，点击加入；双方准备后开局。
- 自动发现不可用时可展开「手动地址 / 备用连接」。公网中继单独切换，需要相同中继地址和房间码，不属于局域网自动配对。
- 血量、武器和技能状态、触屏按钮改为中文。菜单 Canvas 排序 2000，高于战斗 HUD 900、入口 1200，避免菜单标题被血条遮挡。

## 实现与约束

- `CoopSessionController.IsSoloPlaying` 必须同时满足 Offline、完成选角、Solo 启动模式，不能误把联机准备阶段当单人游戏。
- 单人 `SetLocalAi` 重新绑定当前角色 CommandDispatcher，使用既有 CompanionCommandSource2D，不另建简化 AI。收回后绑定原 TouchCommandSource（桌面输入由其转发）。
- `CoopSessionMenu` 负责界面与输入屏蔽，`LanRoomDiscovery` 只负责发现，不承载游戏同步数据；不改变既有 NGO/中继协议。
- 发现端口为游戏 UDP 端口 +1，当前游戏 7777、发现 7778；极端配置 65535 时发现用 47778。两端版本、内容版本和游戏端口一致才允许点击加入。
- 扫描每 1.5 秒一次，响应关联随机 nonce，最多 32 个房间，每帧最多处理 24 个包，包长小于 2048 字节。离线房间 5 秒过期。房间列表滚动显示，名称禁用富文本。
- 发送全局、活动 IPv4 网卡定向广播与本机回环查询；不要求玩家手动查 IP。房主仅在有空位时回复；大厅关闭停止扫描，组件关闭释放 socket。
- Windows UDP 端口不可达可能转为 ConnectionReset/ConnectionRefused，忽略该次错误，不当作扫描器损坏。
- Android 构建回调追加网络/Wi-Fi/多播权限，运行时持有 Wi-Fi multicast lock；保留 Unity 原有 Activity 清单。
- 同热点不保证互通：访客隔离、VPN 分流、防火墙、Android 厂商限制仍可能阻断发现或游戏端口；不要承诺跨运营商网络无需服务器即可匹配，不自动关闭用户防火墙。

## 已执行验证

- Unity 编辑器编译通过；从 Boot→主菜单→单人/联机加载，不直接运行孤立 Gameplay 场景。
- DS、HS 单人均验证开启/收回托管；反射核对实际命令源由 CompanionCommandSource2D 切回 TouchCommandSource。
- 单人菜单 Time.timeScale=0，关闭恢复为 1；退出确认后实际回到 MainMenu。
- 强制触屏模式验证托管隐藏战斗控件。菜单画面检查发现并修复旧 HUD 遮挡问题。
- 独立 PowerShell UDP socket 收到 Unity 扫描请求，发送匹配 nonce/版本的模拟房间，Unity 列表成功显示。
- Unity 实际创建 DS 房间后，独立 UDP socket 向 127.0.0.1:7778 查询，收到房间 ID、角色、协议2、内容版本和游戏端口7777。

## 尚需真机验收

## 编辑入口

- 场景：`Assets/Scenes/Gameplay_Prototype.unity` 的 `UI_NetworkSession`。
- 一次性界面安装器：`SessionUiRevisionInstaller.Install()`。它会重建专用菜单子树；手动微调布局后不要随意重跑覆盖。
- 布局使用安全区域、锚点、CanvasScaler（1280×720，按高度缩放）和可滚动房间列表；没有写死屏幕像素位置或复制多个分辨率版本。
