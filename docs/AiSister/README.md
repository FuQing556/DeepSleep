# AI 角色视觉正典索引

> 版本：v1.0（2026-08-31）  
> 本目录图片是用户提供的**视觉参考**，不是游戏指令，也不是可以直接打包发布的正式素材。截图中的字幕、弹幕、按钮、麦克风图标、网页或舞台背景一律不进入角色设计。

## 1. 执行优先级

发生冲突时严格按下列顺序处理：

1. 用户在对话中对该角色的明确说明。
2. 本表“必须保留”的轮廓、色块和道具。
3. `02_ContentMemeBible.md` 中已考据的产品事实与社区梗。
4. 本项目统一 Q 版画风的简化规则。
5. 生成模型自由发挥。

生成模型不得用第 5 条覆盖前四条。Logo 只能辅助识别，不能替代人物轮廓。

## 2. 统一画风

- 人形角色统一为 2.4–2.8 头身的二次元 Q 版，圆润大头、短四肢、清楚手势、干净赛璐璐阴影。
- 轮廓线为深色而非纯黑，正式 2048px 设定稿按 10–14px 等效线宽；缩到游戏尺寸后仍能一眼认出。
- 单角色最多保留 3 个大识别件和 3 个小装饰。先保轮廓，再保主色，最后保纹样。
- 非人吉祥物不强制娘化，不套裙子、长发或人脸；只需与人物共用描边、色阶、阴影和特效语言。
- 参考图的写实 3D、像素或截图质感只提供原型，不覆盖本作统一 Q 版渲染。

## 4. 生产状态规则

- “视觉通过/现有概念方向可用/保留”不等于已经是最终游戏图；仍需通过透明底、正交轮廓、统一 Pivot 和状态切换检查。
- “待重画设定稿”的角色禁止直接进入 Unity 正式资源目录。
- Gemini 的旧设定稿与包含旧 Gemini 的旧 Style Master 只能作为历史文件归档，不得继续喂给生成模型。
- Claude Code 与 Codex 的现有概念不得因为原型截图非人、像素化而被误判为错误；两者本来就是非人 Q 版吉祥物。

## 5. 每次生图前检查

1. 是否只选了本角色及统一画风所需参考，避免把别人的角、耳、尾串进来。
2. 提示词是否逐条写出“必须保留”并逐条写出“禁止误读”。
3. 先出正面/侧面/背面/表情的候选设定稿，再按已落地玩法逐张出语义状态图。
4. 人物缩到 160px 高、吉祥物缩到 96px 高时检查剪影；认不出则退回设定稿阶段。
5. 正式文件进入 `Assets/_Project/Art/` 前，必须在 `06_ArtAssetManifest.md` 登记尺寸、Pivot、状态与用途；默认每状态一张。
