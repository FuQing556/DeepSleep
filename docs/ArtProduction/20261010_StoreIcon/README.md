# 商店上传图标候选 v01

- 原图：`Assets/_Project/Art/App/AppIcon.png`，作为编辑目标和身份参考。
- 产出：`raw/AppIcon_Store_v01.png`。
- 工具：内置 imagegen，编辑模式，非透明背景。
- 提示词：保留原图蓝发角色、表情、指向动作、服装及“原来是劣等模型”文字；仅将白底替换为蓝紫渐变、少量云雾和星光。正方形、不透明、背景铺满四角，不加圆角或外框。
- 实际输出：1254×1254 PNG；逐像素检查最小 Alpha 为255，全图不透明，符合截图至少512×512的尺寸要求。
- 限制：生成式编辑不是像素级保留，人物和文字笔画存在细微变化；是否接受由用户确认，平台审核结果未验证。
- 仅作为商店上传候选，未替换 Unity 正式图标，也未重新打包。
