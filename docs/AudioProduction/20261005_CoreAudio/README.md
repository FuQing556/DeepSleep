# 核心音效首版：待试听

本目录是音频素材制作记录，不是完整游戏接入验收。声音由可追溯的 Kenney CC0 材质原料剪辑、滤波、做包络和拼层得到；没有使用未授权游戏声音。许可、下载链接及原料包哈希见 [SOURCES.md](SOURCES.md)。

首版输出 56 个 WAV：53 条短音、3 条环境候选。高频的 DS 发射、HS 激光和气泡各 3 个变体；DS 命中/溅射、HS 命中各 2 个，其余每 cue 1 个。UI 的焦点/确认/取消/开页/拒绝各有 DS、HS 一版。没有为尚未确认的音色量产上百个变体。

文件位于 `Assets/_Project/Audio/SFX/{UI,DeepSeek,Harness,Players,Enemies,Flow}` 及 `Assets/_Project/Audio/Ambience`。这是用户授权接入的首版候选，**还未得到人耳听感验收**。

## 怎么听

`previews` 内包含以下顺序样本；每个同名 JSON 写明事件时间、声像、增益及变体，方便指出具体哪一声需要换。

| 文件 | 内容 |
|---|---|
| `01_DS_Shot.wav` | 三个发射变体，柔触点加小颗粒 |
| `02_DS_Impact.wav` | 直击两版、溅射两版 |
| `03_HS_Laser.wav` | 校准、三版激光、两版命中 |
| `04_HS_Melee.wav` | 上挑、下劈、横扫、较轻剑波 |
| `05_Hurt_Guard.wav` | DS 受伤、HS 受伤、盾挡、护航开启/收回 |
| `06_Bubble_Doubao.wav` | 三版泡破、泡撞击、豆包现身/消散 |
| `07_UI_TwoThemes.wav` | 先 DS 五种操作，再 HS 五种操作 |
| `08_Ambience_Candidates.wav` | 黄昏、天空、休息各 6 秒；7 秒切下一段，中间留 1 秒静音 |
| `09_Density_28s.wav` | DS 3→9 轮/秒、HS 0.18 秒连射、三刀、盾挡/受伤、成片泡破、休息和 UI |

28 秒密度示例是离线编排，按一轮一个主发射声、一次泡群一个集体消散制作，不是游戏录回。它不能证明 Unity 混音、手机扬声器、主客机、取消持续声或暂停逻辑已经通过。根代理的接入验收需另行记录。

## 成品边界

短音保持干燥，素材最高峰值不超过 -3 dBFS，切头/尾使用短淡化。输出在不同 cue 之间保留响度层级；UI 焦点低于确认，普通命中低于玩家受伤。不是将所有文件归一到相同峰值。

`HsCharge` 是 480 ms 有限校准声，不是无限循环；中断需要播放端淡出。`GuardEnd` 只作为正常到期的收回候选，不应在倒地、强制清理或切场景时播放。`DoubaoDefeat` 是一次集体消散，不能再叠加每一个气泡的爆裂。

环境候选长 20 秒，可循环；使用的是合成风层与拟音颗粒，**不是远河/城市真实录音**。音量较低是有意保留环境层级；不要为“听清每个细节”在游戏里大幅抬高。真实环境材质仍可在试听后替换。

没有制作背景音乐或对白，不把短完成提示当完整配乐。

## 可复现与数值检查

运行 `D:\python1\python.exe docs/AudioProduction/20261005_CoreAudio/build_audio.py`。输入来自本批次 `sources`；脚本只生成本批 WAV、试听片段和 `manifest.json`，不改 C#、Unity 场景、Prefab 或配置。对已生成的同名候选再次运行会重建它们。

`manifest.json` 包含全部成品路径/AudioCue/主题/变体、峰值、RMS、直流偏移、8 kHz 以上能量比例、边界值、来源与 SHA-256；脚本断言样本有限、无削波及短音边界归零。文件总量约 16.7 MiB，主要是 3 条未压缩立体声环境。最终 Unity 加载/压缩设置由接入环节选择。

本轮未声称亲耳听过、没有自动“音色好听”判定。需用户试听确认的重点仍是：米粒是否有弹性而不湿黏，HS 连射是否刺耳，受伤与盾挡是否容易区分，密集战斗是否疲劳，环境是否需要真实录音替换。
