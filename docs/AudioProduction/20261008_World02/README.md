# 第二世界音效

37条文件、27个声音事件，沿用原生GameAudioService/Mixer和可靠CombatPresentation消息，不增加另一套播放器。素材来自已保存的Kenney CC0材质原料，许可见上一批SOURCES.md；本批无语音、配乐或生成式音频。构建脚本、manifest和audition.wav可复现来源、处理方法、峰值与哈希。听感仍需人耳试听，不将数值检查写成“已试听”。

| 对象 | 接入的声音 |
| --- | --- |
| 递归 | 软质受击、分裂、末级死亡、存活接触；大中小三个池分别绑定 |
| 快应用 | 接触、碎裂死亡；不沿运动轨迹持续播放警报 |
| Claude | 出场、转阶段、全屏预警/切下、锁定/短斩、能量蓄力/发射/爆炸、本体护罩受击、所有对玩家的专属命中、战败 |
| 权限书 | 成批展开、实际封禁、打碎；自然归还使用状态释放音；强制清理/退出不响 |
| 场景状态 | 每轮一次预警、实际生效/结束；四个角不连续叠四声 |
| 环境 | 赛博街区、室内街机节点、Boss雨夜；1.5秒交叉淡化 |
| 其他 | 普攻、升级、受伤、倒地、救援、准备、离开节点、UI等继续复用完整核心系统 |

声音保持低密度：受击/分裂全局冷却0.12～0.16真实秒，每个新事件最多1～2并发；危险切割/能量爆炸保留高优先级声音槽。全屏20条切线只按每轮播放一次，不按线数叠加。新短音解压预加载、环境Vorbis流式，短音有限时长、不新建循环声；菜单暂停、场景退出沿用原有统一清理。普通死亡只消费特殊池声音，不再重复通用死亡音。

联机声音继续由主机发布事实，客户端按context/sequence去重；画面副本不重复推断声音。新增消息种类使协议升到14，内容版本20261008-world02-audio-bestiary-1，旧包不会混房。环境由本端已同步的场景状态选择，不传音频数据。

制作命令：`D:\python1\python.exe docs/AudioProduction/20261008_World02/build_audio.py`。需要numpy/scipy，以及项目Temp/CoreAudioPython中的soundfile/cffi/pycparser；这些不是运行包依赖。SFX峰值不高于-6dBFS，环境-38dBFS RMS；样本有限、首尾归零。不存在自动“音色好听”判定。

自动检查入口：World02ContentChecks、AudioPlaybackChecks、AudioEventIntegrationChecks、NetworkProtocolChecks。双端设备和手机听感留到后续验收，本轮不打包上传。
