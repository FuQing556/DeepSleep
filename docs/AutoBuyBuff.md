# 休息节点自动购买 Buff

入口：局内「菜单」→「自动购买 Buff」，只在休息节点出现。测试场、黄昏故都、"2066"及使用这些场景的图鉴准备节点共用。

点击一次执行一次购买批次，不保存自动开关。依次检查当前商店的第一、第二、第三项，购买第一项可负担且未满级/已解锁的商品；购买引起原有免费换货后重新检查第一项。三项均不可买或全部满级则结束，Token余款保留。不会额外付费刷新，也不会挑目录里未展示的便宜卡牌。

单人先购买当前控制角色，再购买AI队友；两人的钱包分别扣款。联机只购买操作人的角色：客机提交一次请求，房主运行同一购买逻辑，批次结束发送快照和结果反馈，不在客机自行推算余额/等级。自动请求包含节点序号、购买计数，用于拒绝旧节点和已处理过的购买请求。协议16，内容20261009-auto-buy-1。

运行时核心：RestNodeUpgradeController.AutoBuyLocal / ApplyAutoBuy；手动与自动共用TryPurchase。菜单引用为CoopSessionMenu.Upgrades、AutoBuyButton。编辑器AutoBuyBuffInstaller.Install为三个正式玩法场景安装，复制原AI托管按钮并添加独立的DS/HS主题绑定，按钮与托管按钮间保留16参考像素间距。

验证：AutoBuyBuffChecks.Run使用独立非激活对象，不加载玩家档案；120组余额/随机种子，对比逐项手动购买、两角色最终余额与全部等级，检查零余额/满级终止/重复点击/节点外禁止及联机角色/节点/购买计数门禁。另运行NetworkProtocolChecks.RunCatalog、RunUpgradeResults。未完成设备自然实战验收；未打包或上传。
