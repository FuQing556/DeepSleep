# Boss 共用演出时序 · 2026-10-09

用户确认后统一 Kimi / Claude。唯一时间配置为：

`Assets/_Project/Configs/Combat/Encounters/CFG_BossPresentationTiming.asset`

两名 Boss 的表现组件和遭遇配置都引用同一资产；时间采样共用 `BossPresentationTiming`，人物/云、飞行器/雨层、护罩的具体绘制仍各自负责。没有另建战斗框架。

## 实际流程

| 接管后的现实战斗时间 | 表现 |
|---|---|
| 0～3 秒 | 背景渐变；人物、承载物和护罩不可见 |
| 3～4 秒 | 人物与云／飞行器渐入 |
| 4～4.25 秒 | 护罩与血条同步渐入；血条不跟随受击变暗 |
| 4.25～4.75 秒 | 完整形象停留，开战前停顿 |
| 4.75 秒后 | 开始第一招，不额外叠加普通招间间隔 |

转阶段 2 现实战斗秒，保持原半血锁血与招式边界规则。胜利时护罩立即关闭，人物及承载物 1.5 现实秒淡出，背景同时开始 3 秒恢复；胜利结算暂停允许纯退场继续，普通暂停冻结入场、转阶段和背景切换。

时间不受 0.5/2 倍场地效果改变。Kimi 原第四波 20 游戏秒前奏不改，Claude 原 20 现实战斗秒前奏不改，图鉴各自 3 秒前奏仍由图鉴覆盖。本轮没有改普通战斗任务计时。

## 保留内容

- 护罩半径 2.6u／直径 5.2u；常态 Alpha .8，受击 .5，恢复 .1 秒。
- Kimi 球中心 offset `(0,1.16)`，Claude `(0,0)`；人物根缩放、飞行器位置、碰撞不变。
- Kimi 技能间隔 2 游戏秒，每 5 招 5 游戏秒；Claude 一／二阶段 1.2／.9 游戏秒，每 5 招 3 游戏秒。
- Claude 召书动作 1.5 现实战斗秒，之后 1.5 现实战斗秒休息，总计3秒；替代普通/每五招休息（2026-10-09 后续强化）。
- Claude 能量球起手选玩家、发射瞬间才取当前位置定方向，飞行不追踪；最后一枚发射姿势驻足保留0.25现实战斗秒，再恢复移动，不等待球的飞行/爆炸结束。二阶段第二枚蓄力优先显示蓄力姿势。普通短招间仍移动；每5招后的现有3游戏秒周期休息站定显示Idle，召书专属恢复仍替代周期休息，不新增等待时长。
- 生命、伤害、技能内部预警／发射间隔、怪物／书／能量球数值不改。

Claude 本体在接管时准备生命和显示数据，但入场期间不能受伤、不推进接触伤害；人物/盾可见性由演出控制，完整出场才开始攻击。Kimi 继续使用原保护入场语义。

- 旧 Kimi 内容／表现安装器已改用共用配置，不能再把入场回退为 2 秒或背景回退为 1.25 秒。
