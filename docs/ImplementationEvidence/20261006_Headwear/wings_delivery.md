# 小翅膀与叠加佩戴

生成方式：内置 image_gen，transparent_background=true。核对 DS Idle_Base_v01、HS IdleFly_v03、小皇冠生产图，使用 imagegen 与 deepsleep-art-generation 技能。单独的纯装饰翅膀，不改人物/碰撞，不做动画帧。

提示词：
Use case: stylized-concept. Create a production-ready transparent PNG game accessory sprite: ONE PAIR of small cute white feather angel wings, no character, for an anime chibi flying girl in a polished cel-shaded 2D game. Clean delicate dark lavender outlines, soft ivory-white feathers with pale lavender/blue shadow planes, compact rounded fluffy feather roots and 4-5 readable tapered feathers per side. Symmetrical spread upward-outward, pair joined at center back attachment, leave central gap for character torso to cover. Wings should look soft, modest and cute, not huge epic wings, not photoreal, no metallic ornaments or halo or sparkles. Both wings entirely visible and isolated, centered together within square canvas with 10% transparent padding. Crisp non-glowing feather edges, true transparent background, no text, no character or clothing. This is a back-layer wearable for DeepSleep chibi maid characters, meant to be scaled together behind the upper torso. Make the feather structure clear at small game scale.
