# Kimi图鉴与快速挑战（首版）

入口：Boot → 主页「图鉴」→ Kimi →「快速挑战」。先选DS/HS，随后进入天空测试场同款休息节点背景；两名角色各有1000临时Token，可分别在两处强化点配装，传送门沿用原准备规则。

离开节点后：黄昏约3秒，无普通怪物 → 1.25秒渐变月夜、Kimi渐显 → 正式Kimi战斗。复用原2秒入场保护及四技能，生命、阶段、次数盾、增援等均读正式配置。胜利后1.25秒渐变回黄昏，Kimi与脚下云同步退场；结算暂停不会冻结这段纯表现。

2026-10-07：Kimi挑战额外禁止豆包独立遭遇（不只关闭普通刷怪频道），前奏不生成豆包气泡。二阶段五束激光改为屏幕上至下；HS激光在Kimi球罩表面截断、造成伤害并反馈，不穿过球内或从球内继续连锁。

失败沿用节点检查点，回滚该次战斗收益、保留离开配装节点时的强化与剩余余额。胜利页「重新挑战」会开启新一局，重新获得配装Token并重新配装；「返回图鉴」回Kimi详情。选角返回及局内菜单退出也回图鉴。

首版是单人+同伴AI，不提供挑战联机房间。只收录Kimi，未实现豆包/普通小怪的图鉴与挑战。本轮不打包、不上传；用户已要求延期玩法/设备验收，不把编译成功写成实玩验收。

## 数据与扩展边界

2026-10-07 修正：配装背景不能只换贴图。`PreparationLayout`保存第一关休息节点的背景位置/缩放及热点位置、缩放、Box尺寸/偏移、启停状态；`BestiaryInstaller.CapturePreparationLayout()`显式读取第一关玩家现有参数，保存到图鉴配置。挑战只改变本局实例，不修改正式场景。相机沿用相同的5.4正交尺寸。已针对购买/离开问题做编辑器Play检查：两台装置的空间交互、实际购买扣款、中央传送门与AI准备、接入Kimi战斗；其他验收仍按下方清单延期。

- `Assets/_Project/Configs/Progression/Bestiary/CFG_Bestiary_Kimi.asset`：展示图、简介/技能说明、正式关卡、入口战斗段4、双方各1000Token、3秒前奏、配装背景/说明。
- `Progression/Bestiary/BestiaryEntryDefinition`：入口及展示数据。`BestiaryMenuView`：首条目详情页，不模拟战斗。
- `GameLaunchContext.Challenge`/`GameSceneRouter.StartChallenge`：只保存一次启动意图，经原场景退出链重进正式World01。普通StartLevel或回主页清掉Challenge。
- `ChapterRunController`仍是唯一章节状态机：挑战跳过前三波、禁用普通刷怪频道、用原休息节点/强化/检查点、结束时不调用永久奖励或通关成就。没有挑战专用复制场景或第二套Boss代码。
- `KimiEncounter.Begin`的可选前奏参数只作用于本局；正式关卡仍读配置20秒，不改共享资产。Kimi出场渐显由既有`KimiBossPresentation2D.EntryFadeSeconds`控制。

临时Token/强化只存在场景实例，退出销毁；挑战不增加鲸元券、不标记正式通关、不报告开始旅途/复活/无伤通关成就。饰品仍读真实佩戴配置，主题仍按玩家选角保持偏好。
