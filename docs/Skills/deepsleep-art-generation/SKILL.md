# DeepSleep 生图

项目内维护源：`docs/Skills/deepsleep-art-generation/`；安装副本位于当前 Codex 技能目录。修改规则时同步源与安装副本，不另建同名变体。

服务这个项目，不把本文变成其他项目的通用审美。用户当前明确要求优先于旧设计、示例提示词和历史失败记录。目标是可爱、好看、动作自然且能直接进入本项目制作流程的素材，不是把提示词约束全部凑齐。

## 先核对最小必要事实

- 工程根以当前工作区为准：应含 `Assets/_Project` 与 `docs/agent.md`。不固定盘符，不扫描整盘；其他工作区显式调用时请用户提供项目路径。
- 角色或专属武器/VFX：读取 [角色与特效母图](references/visual-identity.md)，实际查看本次采用的母图。做尺寸/导入交付时，再读取 [尺寸与 Unity 边界](references/size-and-integration.md)。
- 只读取本次相关文件。已有可靠参考和用户确认不必重新询问，不因每一张图重复审计全工程。
- 向用户简述本批目标、参考与拆层；已有明确整套任务可以连续完成。只在身份、动作语义、风格方向或破坏性替换等会实质改变结果的选择上停下确认。
- 若已确认原图不可读取，说明缺的是哪张参考；不改成无参考盲画。用户只要抠图时不调用生图重画人物。

## 生图前在内部写清一张短卡

`对象/状态 → 已确认参考 → 一个主要动作 → 视角与飞行/睡眠状态 → 人物/武器/VFX拆分 → 画布与透明需求 → 实际用途`

例：HS 上挑指挥姿态，以 HS 常态确认身份；自然向上引导悬浮剑，人物不握长剑；独立全身人物透明图，剑和剑气由 Unity 组合。

不是要求每次给用户填表。缺少已决定的事实应查相关文件；真正未决定且会改变作品的事项才问。

## 提示词写法：少而相容

1. 用内置 imagegen，遵守其技能/工具调用要求；明确每张输入是身份参考、修改目标还是特效风格参考。
2. 简洁说明“同一人物、相同头身/服装/线稿，改成某动作”；一个姿态一个主要动势，其余身体自然配合。不要把参考待机姿态也锁死。
3. 提交前顺着肩→肘→腕、胸腔→骨盆→腿想一遍。不得同时要求躯干正面、骨盆强侧面、反向肩膀、过肩手势和原姿态不动；减少矛盾，不继续堆解剖术语和负面词。
4. 角色的左手不是画面左侧。只在任务需要时写明解剖侧别；画面验收必须看拇指、掌背和前臂连接，不能只数五根手指，更不能拿另一只手镜像粘上。
5. 编辑只列本次改动与重要不变量。裙子不好看就改裙子，不顺手改脸、发型、头身和动作。用户否定姿态并要求重画时，不继续局部修补原坏结构。
6. 参考图已经确定的服装由图传递；避免把每个小配饰写成一套新的、互相争抢构图的要求。不会飞的敌人也不因此被强制画成飞行生物。

可改写的短提示示例（不是每次全部粘贴）：

> 以参考中的 HS 为同一人物，保持脸型、头身、眼镜、黑白红女仆装和虎鲸尾的画风。她在空中自然做出向上引导悬浮剑的动作，身体连贯、姿态清楚，与待机有区别。全身完整、留出透明边距，人物不带剑或剑气，真实透明背景。

局部编辑示例：

> 只调整目标图裙摆，服装结构参考 HS 常态。黑裙与白围裙自然飘动，简洁白蕾丝和细红纹，不大幅翻卷、不加多层蛋糕裙。保留已确认的脸、比例和动作。

## 分组生产，不混合职责

- 普通状态图：单张完整人物，默认不带天空、地面投影、残影、武器轨迹。状态切换残影由 Unity 生成，不画进新图。
- HS 当前近战：人物指挥动作、量子剑、三种剑气分开；“拼贴”是 Unity 内组合，不是 PS 烘成一图。不必手握剑，不为容纳长剑把人缩小。剑是否需要不同透视版本取决于动作；没有确认的数量不要自行扩单。
- 技能肖像内盘可保留指定背景；内盘、透明外环分开。圆形 Sprite 不会自动裁掉方图四角，要交付圆形 Alpha 或明确要求 Mask/Shader。
- 激光炮口、可重复束身、边缘碎晶、外框、命中闪光分开；束身无起止端帽，沿 X 可循环。不得用一张完整激光插画替代全部可扩展部件。
- 背景按滚速分层；循环与静态装饰不同。真正循环图需双副本接缝预览，不能用“够宽”代替可循环。
- 每批明确全部依赖，但只制作用户本次授权范围；不自行添加帧动画、额外角度或新角色设定。

## 色底交接与验收

- 本项目所有后续生图统一要求饱满、均匀、无纹理且与主体色差显著的纯色背景，再由本地流水线色键抠图。禁止继续要求生图模型直接输出透明背景或棋盘预览。底色按主体配色选择；DS 蓝白素材优先高饱和绿色，含绿色主体则换高饱和品红等互补底色。
- 纯色底只是生产中间图，必须本地去色边并检查半透明光晕，不能直接当生产 PNG。
- 用户已允许本地抠图；交接给 `deepsleep-sprite-matting`。抠图脚本只去背景/边缘，不负责生成或纠正肢体。底色按素材配色选择，不能为所有对象硬指定蓝/绿底；尤其 DS 蓝发不可盲抠蓝底。
- 全身 100% 查看手臂连接、手的侧别、腰胯腿朝向、脸和裙装；再和母图并排缩到实际游戏量级看。外轮廓、头发和尾巴能完整容纳，不能裁边后称作动作完整。
- 同一问题连续两次未改善，就停止同类盲修，展示候选和实际提示词，改变明确的冲突条件或向用户确认方向；不要静默消耗整下午额度。已通过图锁定，不陪其他坏图重画。
- 技术检查不代表用户喜欢，也不代表 Unity 接入完成。不得承诺 skill 能保证每次生成解剖零错误。

## 文件与交付

候选沿用 `docs/ArtProduction/<日期_任务>/raw/`；透明候选 `ready/`；对照图 `previews/`。原图保留，用版本号区分修改。延用本项目 `SPR_DS_*`、`SPR_HA_*`、`VFX_*`、`TEX_*` 的已有命名，不自动迁移旧文件。

交付给用户：当前结果预览、实际文件绝对路径、改了什么/未完成什么。把提示词、引用母图、工具模式和已知处理限制记录到该批交付说明。只有得到相应替换授权后才导入正式目录，不改碰撞体/配置来掩盖坏图。
