# DeepSleep 本地抠图

项目内维护源：`docs/Skills/deepsleep-sprite-matting/`；安装副本位于当前 Codex 技能目录。修改规则时同步源与安装副本，不另建同名变体。

本技能处理背景和画布，不重新设计角色。用户已明确允许本项目用本地 Python 做抠图、去边和尺寸检查。不能把“修手/改动作”的生成修改夹在抠图里；用户明确要求局部像素修复时也应另列修改范围。

工程根含 `Assets/_Project` 与 `docs/ArtProduction/Tools`。路径以当前工程为准，不硬编码用户名、盘符或Python位置。优先可用的 Pillow/NumPy 运行时，不因工具缺失静默下载安装重型模型。

## 一次准备，一批执行

1. 锁定源文件及其 SHA256；已确认源图只读保留，不拿失败 cutouts 再抠一遍。实际查看图片，辨明人物白衣/黑发、光晕、封闭空隙和背景类型。
2. 读取 [方法选择与已知陷阱](references/methods.md)，为每张图选方法。不同源图不能盲套同一阈值/种子。
3. 复用现有工具/当前批配方。候选产物单独保存，参数调节同一脚本即可，不为每次试抠复制一个新流水线。
4. 运行本技能 `scripts/inspect_sprite.py` 得到Alpha报告及白/暗/天空底预览；对关键缝隙/保护点做原尺寸检查。脚本结果只作测量，不自动判定美术通过。
5. 一批目标明确时连续完成，再给用户结果；不每张图停下来问“可以继续抠吗”。结构错误应退回生图，背景问题留在本地处理，不来回重画已批准人物。

## 绝对不能互换的概念

- 看起来有棋盘≠透明。RGB/RGBA全不透明可能烘了棋盘；即使有部分透明，也可能衣袖之间还残留棋盘。
- 四角透明≠抠干净。全图全透明也能通过四角检查，但人物没了。必须检查主体、白围裙、头饰、手指缝、发丝内孔和尾巴弯内侧。
- 白色≠背景，黑色≠透明。不能全局删灰/白导致脸与围裙穿孔，也不能全局去黑吃掉HS衣服和红黑晶体。
- 真实透明素材无需再次色键。半透明光效可以没有任何 alpha=255 像素，不能因此判废或强行加硬边。
- 抠图≠无损还原。对已与棋盘混合的柔光，原前景和alpha通常不能唯一恢复；近似重建必须说明光晕变化，不声称恢复原生透明。
- 直通Alpha与预乘Alpha不混用；不能把带底色的边缘再乘一遍Alpha，制造白/黑边。需要特殊混合材质时记录，不静默换材质补救。

## 不破坏画布与比例

保留高分源画布，不非等比缩放、不自动裁到紧贴发丝或剑尖。需要去多余留白/扩画布时另存版本并记录偏移及缩放，让Pivot可复现。纯抠图保持人物内部RGB与位置；边缘去污染允许在轮廓窄带内改RGB/alpha，不全身换色。

DS/HS头身以已确认母图为准，站立飞行与趴飞/睡眠不强制同宽高。PNG抠图不修改PPU、视觉倍率、Collider、命中特效选项和Prefab；这些在Unity接入另行处理。

## 验收与交付

- 最少看白底、暗底、天空底：白底查黑边/残留黑块，暗底查灰白棋盘和白边，天空底看实际融合。再打开关键区域原尺寸，不仅看缩略图。
- 检查重要前景点仍保留、确认背景点透明；全透明、无透明、明显裁边、衣服穿孔、被吃掉的黑色结构均不能标通过。
- 发光特效需要半透明过渡；把整片软光阈值切掉虽然“四角干净”，也不是合格特效。
- 困难缝隙先局部遮罩/有边界的种子；一次针对性调整后复查该区域和附近衣物。两次局部方案仍没有改善时保留最佳候选，指出具体区域/方法限制，不继续无上限扩大阈值或侵蚀人物。
- `raw/`原图、`ready/`透明候选、`previews/`验收图统一在该批 `docs/ArtProduction/<日期_任务>/`。某批旧 `cutouts/` 已失败，不能按名字认为有效；只有本批清单列出的输出是交付入口。
- 批次报告至少记源hash、输出、尺寸/可见bbox、Alpha统计、方法参数/遮罩、已知限制、是否用户验收及是否Unity导入。提供可点击绝对路径，不把工具成功当视觉成功。

## 只读检查工具

命令中的 `<python>` 使用当前已验证解释器；相对路径从项目根执行：

```text
<python> <本技能目录>/scripts/inspect_sprite.py docs/ArtProduction/<批次>/ready/<图>.png --output-dir docs/ArtProduction/<批次>/previews/audit --require-alpha
```

如已目测确认像素位置，可加 `--keep 600,500 --clear 20,20` 检查保护点/背景点；不得把例子坐标当某张图的正确坐标。静态背景不传 `--require-alpha`。此工具不修改输入，也不负责重画或抠图算法。
