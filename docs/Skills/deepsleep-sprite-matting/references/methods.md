# 方法选择与项目工具

下面的工具位于项目，不需要复制到每个新批次。脚本是可配置算法，不是能理解人物解剖的分割模型。

## 先按内容选方法

| 输入 | 首选处理 | 不可盲用的情况 |
| --- | --- | --- |
| 原生透明PNG | 原样保留像素，做预览与Alpha检查 | 仍需看内部是否烘了棋盘；不因有Alpha就放行 |
| 白/灰/假棋盘且人物外轮廓清楚 | 从画布边界连通的中性区域移除；封闭洞用已检查的局部种子/遮罩 | 白衣与背景连通时会漏进人物，必须保护前景，不是提高阈值硬抠 |
| 绿色均匀底，人物无绿色 | 绿幕色键与窄边去污染 | DS蓝发不等于可以任意色键；人物有绿光时会误删，换遮罩/方法 |
| 黑底纯光能粒子 | 发光分量重建直通Alpha，可用black_emission | 不用于HS黑发黑裙、剑身和黑色碎晶；黑色实心结构不能恢复成透明 |
| 假棋盘混合黑红晶体与柔光 | 分离需保留的实心结构和近似发光边缘，局部验收 | 无法仅从RGB唯一恢复原Alpha；阈值过低残棋盘，过高光晕消失 |
| 天空、复杂背景或颜色重合严重 | 局部显式遮罩/专门分割并人工检查 | 不把所有蓝色当背景；方法不可靠时报告，不偷偷重画批准图 |
| 技能内盘指定有背景 | 保留内盘合成，仅处理盘外Alpha | 不把用户要的背景整块抠走；或交接显式圆形Mask |

## 现有通用工具

`docs/ArtProduction/Tools/sprite_matte.py`：

- `connected_neutral(image, minimum, maximum, chroma, seeds, edge_dematte)`：边缘连通+种子抠除。阈值不是整项目常量；无范围的seed会沿所有连通中性色扩散，处理小孔优先在局部ROI内限定。
- `neutral_edge_dematte(image, background_mask)`：只处理一像素轮廓窄边，基于附近较暗轮廓估计；适用于已核对的深色描边，不是所有透明发光材质通用去边。
- `green_screen(image, cutoff, backdrop_tolerance, emission_edges)`：仅对不含绿色主体的色底；皮肤 G 高于 B 不能单独判绿边，绿色需同时相对 R/B占优。阈值需要测背景取样，背景不一定是 `(0,255,0)`。
- `black_emission(image, cutoff)`：纯光能。RGB×alpha在黑底重建输入，不保留黑色实体。
- `report`、`preview`：统计和合成预览。四角检查不能取代验收。

`prepare_sprite_batch.py` 支持显式 JSON `assets:[{source,output,method,parameters}]`；method为neutral/green/emission/alpha。它的旧校验要求存在完全不透明像素，**不适合直接验收全半透明VFX**；遇到这种素材不为了通过它而硬化Alpha。该工具允许覆盖配方输出，所以必须事先选择独立版本路径。复杂ROI用当前批脚本，不绕开保护检查。

## 本次可追溯范例，不是全局模板

`docs/ArtProduction/20260908_HarnessQuantumSword/finish_characters.py` 示范边界抠除后在有限矩形内处理发丝/尾部内孔，再处理窄边；其种子、矩形和阈值只对应该批原图。HS白头饰曾因阈值过宽受损，后来通过限定局部阈值保留；不要把这些坐标应用到新姿态。

同批 `finish_effects.py` 示范红色发光与黑色晶体的近似分离。它改变柔光强度，不能被描述成无损透明恢复，也不适用于蓝白DS效果。该批原生Alpha剑与横劈剑气保持原样。

旧 `checkerboard_matte.py`、`RemoveLightCheckerboard.ps1`、`repair_sweep_hand.py` 等属于历史尝试，不能仅凭文件存在就选作首选工具。当前任务优先使用已理解的算法与本批配方，不批量运行全部旧脚本。

## 关键验收点

- 角色：白围裙/蕾丝、脸与手、眼镜边、呆毛内孔、发丝之间、尾巴环内侧、裙摆下方。检查前景Alpha与内部RGB不被误改。
- HS武器/VFX：黑色结构仍在，白芯不被挖空，红晕无棋盘块。黑红效果不能套“去所有黑色”。
- DS蓝发/白衣和治疗白十字：背景色重合时不可粗暴扣蓝/白。
- Alpha=0位置隐藏RGB可以清零以免采样污染，但不要因此侵蚀可见描边或抹掉合法暗色；颜色空间和材质混合问题与背景残留分开诊断。
- 画布扩边不是放大人物；不同pose保留可重现锚点，不能独立紧裁后仍声称Pivot一致。

未经用户授权不替换正式资产；写脚本和生成预览都在批次目录，不写 Unity `.meta` 或移动整套资产。
